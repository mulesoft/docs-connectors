= Upgrading and Migrating Microsoft Dynamics CRM Connector to 4.x

Upgrade Anypoint Connector for Microsoft Dynamics CRM (Microsoft Dynamics CRM Connector) from version 3.x to version 4.x.

== Supported Upgrade Paths

[%header,cols="50a,50a"]
|===
|From Version | To Version
|3.x |4.x
|===

== Changes

=== 4.0

* This connector is now compatible with Java 17 only. 
* The connector now uses Apache CXF 4.2.4, and web services classes move from the `javax` namespace to the `jakarta` namespace. Custom code that uses `javax` web services classes bundled with the connector must use `jakarta`.
* The connector package no longer includes the legacy Microsoft Dynamics CRM 2015 WSDL code generation kit.
* These libraries are upgraded to address reported security vulnerabilities:

** The `jackson-core` and `jackson-databind` libraries are upgraded to version 2.22.3.
** The `bcpkix-jdk18on` and `bcutil-jdk18on` libraries are upgraded to version 1.86.
** The `wss4j` library is upgraded to version 4.0.2.
** The `xmlschema-core` library is upgraded to version 2.3.3.
** The `guava` library is upgraded to version 33.7.2-jre.
** The `httpclient5` library is upgraded to version 5.6.5.
** The `httpcore5` and `httpcore5-h2` libraries are upgraded to version 5.4.4.
** The `woodstox-core` library is upgraded to version 7.2.2.
** The `xmlsec` library is upgraded to version 4.0.4.
** The `neethi` library is upgraded to version 3.2.4.
** The `commons-lang3` library is upgraded to version 3.21.0.
** The `commons-codec` library is upgraded to version 1.23.0.

== Requirements

Ensure your system meets the following compatibility requirements before you perform the upgrade:

[%header%autowidth.spread]
|===
|Application/Service|Version
|Mule runtime |4.9.0 and later
|Java |17
|Dynamics CRM |2013, 2015, and 2016
|===

== Upgrade Prerequisites

Before you perform the upgrade, you must:

. Create a backup of your files, data, and configuration in case you need to restore to the previous version.
. Ensure that your environment meets the version 4.x requirements, including Java 17 and Mule runtime 4.9.0 or later.
. If your app uses `javax` web services classes bundled with the connector, update that code to use `jakarta`.
. If your app uses the Kerberos connection type, configure the CRM instance to support the `aes128-cts-hmac-sha1-96` or `aes128-cts-hmac-sha256-128` encryption types. Java 17 enforces these encryption types. You can set `allow_weak_crypto` to `true` in the `krb5.conf` file as a workaround. For more information, see xref:ms-dynamics-crm-connector-reference.adoc#dynamics-crm-config_kerberos[Kerberos].
. Install Microsoft Dynamics CRM Connector 4.x to replace the connector operations that were previously included in Microsoft Dynamics CRM Connector 3.x.

== Upgrade Steps

Follow these steps to perform the upgrade from Microsoft Dynamics CRM Connector 3.x to Microsoft Dynamics CRM Connector 4.x:

. In Anypoint Studio, create a Mule project.
. In the *Mule Palette* view, click *(X) Search in Exchange*.
. In *Add Modules to Project*, type `crm` in the search field.
. Click *Microsoft Dynamics CRM Connector* in *Available modules*.
. Click *Add*.
. Click *Finish*.
. Verify that the `mule-microsoft-dynamics-crm-connector` dependency version is `4.x.x` in the `pom.xml` file, where `x.x` is the minor release and patch version number. For example, if you are upgrading to version 4.0, the dependency version in the `pom.xml` file should be `4.0.0`.

Studio upgrades the connector automatically.

== Verify the Upgrade

After you install the latest version of the connector, follow these steps to verify the upgrade:

. In Studio, verify that there are no errors in the *Problems* or *Console* views.
. Check the project `pom.xml` file and verify that there are no problems.
. Test the connection and verify that the operations work.

== Troubleshooting

If there are problems with caching the parameters and caching the metadata, try restarting Studio.

== Revert the Upgrade

If it is necessary to revert to the previous version of Microsoft Dynamics CRM Connector, change the `mule-microsoft-dynamics-crm-connector` dependency version in the project's `pom.xml` file to the previous version.

You must update the project's `pom.xml` file in Anypoint Studio.
