= Kerberos Module 

Kerberos Module v0.1

NOTE: Requires Mule 4.10 or later and Mule HTTP Connector 1.11 or later.

Kerberos Module adds Kerberos (SPNEGO) proxy authentication support for the Mule HTTP Connector.
+
IMPORTANT: The Kerberos module adds only proxy authentication. It does not implement request-based Kerberos authentication for HTTP requests.

== Before You Begin

To use this module, you must be familiar with:

* Anypoint Connectors
* Mule runtime engine (Mule)
* Elements and global elements in a Mule flow
* Creating a Mule app using Anypoint Studio (Studio)
