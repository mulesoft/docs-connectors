= Kerberos Module 1.0 Reference
:page-aliases: connectors::kerberos/kerberos-documentation.adoc

Kerberos Module adds Kerberos (SPNEGO) proxy authentication support for the Mule HTTP Connector.

== Configuration

[[kerberos-proxy-authentication]]
=== Kerberos Proxy Authentication

Use `<kerberos:proxy-authentication>` to configure Kerberos proxy authentication for the Mule HTTP Connector.

==== Parameters

[%header,cols="20s,20a,35a,20a,5a"]
|===
| Name | Type | Description | Default Value | Required
| Host | String | Proxy host. |  | x
| Port | Number | Proxy port. |  | x
| Principal | String | Kerberos principal, for example, `user@EXAMPLE.COM`. |  | x
| Realm | String | Kerberos realm, for example, `EXAMPLE.COM`. |  | x
| Use Ticket Cache | Boolean | Uses the local Kerberos ticket cache for authentication. | true |
| Keytab Path | String | Path to a keytab file for obtaining credentials when not using a ticket cache. |  |
| Krb5ConfPath | String | Path to Kerberos configuration file (krb5.conf) containing KDC and realm settings. |  |
| TicketCachePath | String | Path to Kerberos credential cache file for ticket cache authentication. Defaults to system ticket cache location. |  |
| Non Proxy Hosts | String | Hosts to reach directly, bypassing the proxy. |  |
| Service Type | String | Kerberos service type for building the SPN. | HTTP |
|===

==== XML Example

Use `<kerberos:proxy-authentication>` to configure Kerberos proxy authentication in an HTTP Connector request configuration. This example shows how to set parameters such as `host`, `port`, `principal`, `realm`, `useTicketCache`, and `serviceType`.

[source,xml,linenums]
----
<mule xmlns:kerberos="http://www.mulesoft.org/schema/mule/kerberos"
      xmlns:http="http://www.mulesoft.org/schema/mule/http"
      xmlns="http://www.mulesoft.org/schema/mule/core"
      xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
      xsi:schemaLocation="http://www.mulesoft.org/schema/mule/core http://www.mulesoft.org/schema/mule/core/current/mule.xsd
                          http://www.mulesoft.org/schema/mule/http http://www.mulesoft.org/schema/mule/http/current/mule-http.xsd
                          http://www.mulesoft.org/schema/mule/kerberos http://www.mulesoft.org/schema/mule/kerberos/current/mule-kerberos.xsd">

  <http:request-config name="httpCfg">
    <http:proxy-config>
      <kerberos:proxy-authentication
          host="proxy.example.com"
          port="8080"
          principal="user@EXAMPLE.COM"
          realm="EXAMPLE.COM"
          useTicketCache="false"
          serviceType="HTTP"/>
    </http:proxy-config>
  </http:request-config>

</mule>
----
