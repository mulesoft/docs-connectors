= Using Anypoint Code Builder to Configure Tracing Module 1.3

Anypoint Code Builder (ACB) editors help you design and update your Mule applications, properties, and configuration files.

To add and configure a module in Anypoint Code Builder:

. <<create-integration-project,Create an integration project>>.
. <<add-module-to-project,Add the module to your integration project>>.
. <<configure-source,Configure a source for the module's flow>>.
. <<add-module-operation,Add a module operation or scope to the flow>>.

When you run the module, you can view the app log to check for problems, as described in <<view-app-log,View the App Log>>.

If, after reading this topic, you need additional information about the module fields, see the xref:tracing-module-reference.adoc[Tracing Module Reference].

[[add-module-to-project]]
== Add the Module to Your Integration Project

Add Tracing module to your integration project to automatically populate the configuration XML file with the module's namespace and schema location and to add the required dependency to the project's `pom.xml` file:

. In the Explorer view, open the configuration XML file for your project, such as `my-project-name.xml`.
. Click the image:anypoint-code-builder::icon-tree-view.png["Show Mule graphical mode icon",15,15] (*Show Mule graphical mode*) icon in the activity bar to open the canvas UI if it doesn't open automatically.
. In the canvas UI, click the image:anypoint-code-builder::icon-plus.png["Add component icon",15,15] (*Add component*) icon.
. In the *Add Component* panel, click the image:anypoint-code-builder::icon-search-exchange.png["Search in Exchange icon",15,15] (*Search in Exchange*) toggle and search for `tracing`.
. Click *Tracing Module* and then click the operation or scope to add.

Adding a module to an integration project does not make that module available to other projects in your Anypoint Code Builder workspace.

[[view-app-log]]
== View the App Log

To check for problems, you can view the app log in the Output panel of Anypoint Code Builder.

Unless the log file path is customized in the app's log file (`log4j2.xml`), you can also view the app log in the default location `MULE_HOME/logs/<app-name>.log`.
