= Upgrading and Migrating NetSuite Connector to 13.x
:page-aliases: connectors::netsuite/netsuite-connector-upgrade-migrate.adoc

Upgrade Anypoint Connector for NetSuite (NetSuite Connector) from version 12.x to version 13.x.

== Supported Upgrade Paths

[%header,cols="50a,50a"]
|===
|From Version | To Version
|12.x |13.x
|===

== Changes

=== 13.0

* Spring is no longer packaged in `mule-soap-engine`. The engine uses a Spring bus only when Spring is already visible to the application. Otherwise it uses the non-Spring CXF bus, which does not read a classpath `cxf.xml` file. NetSuite Connector does not call Spring or CXF. *Token-Based Authentication* and the connector HTTP client are unchanged.
* If your application uses a custom `cxf.xml` file, re-test it after you upgrade. See xref:netsuite-connector::netsuite-troubleshooting.adoc#cxf-xml-not-applied[Custom cxf.xml settings aren't applied].
* These libraries are upgraded to address reported security vulnerabilities:

** The Apache CXF library is upgraded to 4.2.4.
** The `guava` library is upgraded to version 33.8.0-jre.
** The `commons-collections4` library is upgraded to version 4.6.0.
** The `jackson-databind` and `jackson-dataformat-xml` libraries are upgraded to version 2.23.0. 
** The `gson` library is upgraded to version 2.15.0.

== Requirements

Ensure your system meets the following compatibility requirements before you perform the upgrade:

[%header%autowidth.spread]
|===
|Application/Service |Version
|Mule runtime |4.9.0 and later
|Java |17
|Anypoint Studio |7.21 and later
|===

== Upgrade Prerequisites

Before you perform the upgrade, you must:

. Create a backup of your files, data, and configuration in case you need to restore to the previous version.
. Ensure that your environment meets the version 13.x requirements, including Java 17, Mule runtime 4.9.0 or later, and Anypoint Studio 7.21 or later.
. If your application uses a custom `cxf.xml` file, plan to re-test that file after the upgrade.

== Upgrade Steps

Follow these steps to perform the upgrade from NetSuite Connector 12.x to NetSuite Connector 13.x:

. In Anypoint Studio, create a Mule project.
. In the Mule Palette view, click *Search in Exchange*.
. In the *Add Dependencies to Project* window, enter `netsuite` in the search field.
. In the *Available modules* section, select *NetSuite Connector* and click *Add*.
. Click *Finish*.
. Verify that the `mule-netsuite-connector` dependency version is `13.x.x` in the `pom.xml` file, where `x.x` is the minor release and patch version number. For example, if you are upgrading to version 13.0, the dependency version in the `pom.xml` file should be `13.0.0`.

Studio upgrades the connector automatically.

== Verify the Upgrade

After you install the latest version of the connector, follow these steps to verify the upgrade:

. In Studio, verify that there are no errors in the *Problems* or *Console* views.
. Check the project `pom.xml` file and verify that there are no problems.
. Test the connection and verify that the operations work.
. If your application uses a custom `cxf.xml` file, confirm whether the HTTP settings, timeouts, interceptors, or WS-Security in that file still apply. See xref:netsuite-troubleshooting.adoc#cxf-xml-not-applied[Custom cxf.xml settings aren't applied].

== Troubleshooting

If custom `cxf.xml` settings no longer apply after the upgrade, re-test the integration. NetSuite Connector does not include Spring, and adding Spring is not a documented fix for this connector.

If there are problems with caching the parameters and caching the metadata, try restarting Studio.

== Revert the Upgrade

If it is necessary to revert to the previous version of NetSuite Connector, change the `mule-netsuite-connector` dependency version in the project's `pom.xml` file to the previous version.

You must update the project's `pom.xml` file in Anypoint Studio.
