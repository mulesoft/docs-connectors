= Upgrading and Migrating NetSuite Connector to Version 12.x
:page-aliases: connectors::netsuite/netsuite-connector-upgrade-migrate.adoc

Upgrade Anypoint Connector for NetSuite (NetSuite Connector) to version 12.x.

== Supported Upgrade Paths

[%header,"cols=50a,50a"]
|===
|From Version | To Version
|11.x |12.x
|===

== Changes in This Release

* Spring Framework is upgraded to 6.2 (from the 5.3.x line) for security and compatibility with current Mule runtimes and SOAP Engine 2.x.
* SOAP Engine is upgraded to 2.3.1 (from 1.12.0); Spring dependency versions are supplied by the SOAP Engine and connector parent POM.
* The connector parent POM (`mule4-connectors-parent`) is upgraded to 9.0.4 (from 2.0.1). MUnit versions are managed by the parent where applicable.
* Java 17 is required at compile time and runtime. The minimum Mule version for NetSuite Connector 12.x is 4.9.0.
* The deprecated global configuration parameter `omitInternalIdFromCustomFields` (deprecated in 10.x) is removed. Remove it from configuration or flow XML if it is still present, and review integrations that depended on custom field names that included internal IDs. See xref:netsuite-reference.adoc[NetSuite Connector Reference] for configuration and metadata details.
* Operations support an optional *Error Mappings* parameter for mapping error categories to custom error types. See xref:netsuite-reference.adoc[NetSuite Connector Reference] for the `Error Mapping` type.
* Deprecated Mule Runtime internal APIs used in earlier connector builds are replaced with Apache Commons IO and standard `javax.xml.stream` APIs; application flows do not need changes unless you extended the connector.

== Requirements

Ensure your system meets the following compatibility requirements before you perform the upgrade:

[%header%autowidth.spread]
|===
|Application/Service |Version
|Mule |4.9.0 and later
|Java |17
|SOAP Engine (transitive) |2.3.1
|===

If you use NetSuite Connector 10.x or earlier, upgrade to the latest 11.x release first using the *Upgrading and Migrating NetSuite Connector* topic in the NetSuite Connector 11.x documentation. Version 12.x uses the same SOAP/XML metadata and operation model as 11.x.

== Upgrade Prerequisites

Before you perform the upgrade, create a backup of your files, data, and configuration in case you need to restore to the previous version.

== Upgrade Steps

Follow these steps to perform the upgrade to version 12.x:

. In Anypoint Studio, create a Mule project.
. In the *Mule Palette* view, click *Search in Exchange*.
. In *Add Dependencies to Project*, enter `netsuite` in the search field.
. In *Available modules*, select *NetSuite* and click *Add*.
. Click *Finish*.
. Verify that the `mule-netsuite-connector` dependency version is 12.x in the `pom.xml` file in the Mule project.

Studio upgrades the connector automatically.

== Post-Upgrade Steps

After you install the latest version of the connector, remove any `omitInternalIdFromCustomFields` attribute from the NetSuite global configuration, confirm each deployment uses Mule 4.9.0 or later with Java 17, and use *Token-Based Authentication*. If you rely on custom error handling, review optional *Error Mappings* on operations and error codes as described in xref:netsuite-reference.adoc[NetSuite Connector Reference] and xref:netsuite-troubleshooting.adoc[Troubleshooting NetSuite Connector].

== Verify the Upgrade

After you install the latest version of the connector, follow these steps to verify the upgrade:

. In Studio, verify that there are no errors in the *Problems* or *Console* views.
. Verify that there are no problems in the project `pom.xml` file.
. Test the connection to verify that the operations work.

== Revert the Upgrade

If it is necessary to revert to the previous version of NetSuite Connector, change the `mule-netsuite-connector` dependency version in the project's `pom.xml` file to the previous version.

You must update the project's `pom.xml` file in Anypoint Studio.
