= Troubleshooting Einstein AI Connector 1.1 

== Empty API Instance URL Error

If you receive the `Empty API Instance URL` error, confirm that you completed Einstein Generative AI setup correctly for your Salesforce org. For more information, see https://developer.salesforce.com/docs/ai/agentforce/guide/org-setup.html[Set Up Einstein Generative AI].
