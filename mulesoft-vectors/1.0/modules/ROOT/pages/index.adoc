= MuleSoft Vectors Connector 1.0 
:lc-connector-name: mulesoft-vectors

Anypoint Connector for MuleSoft Vectors (MuleSoft Vectors Connector) provides access to a broad number of external vector stores and databases. MuleSoft Vectors Connector can be used with other connectors (for example, MuleSoft Inference Connector or Einstein AI Connector) and provides MuleSoft users seamless access to vector stores for implementing advanced Retrieval Augmented Generation (RAG) use cases within Anypoint Platform.

For information about compatibility and fixed issues, see the MuleSoft Vectors Connector release notes. 

== Before You Begin

To use this connector, you must be familiar with:

* Anypoint Connectors
* Mule runtime engine (Mule)
* Elements and global elements in a Mule flow
* How to create a Mule app using Anypoint Code Builder or Anypoint Studio

Before creating an app, you must have:

* Java 17 (required for compilation and runtime)
* Apache Maven
* Credentials to access the MuleSoft Vectors Connector target resources
* Anypoint Platform
* The latest versions of Anypoint Code Builder or Anypoint Studio

== Key Features

MuleSoft Vectors Connector simplifies vector database integration into Mule applications with:

* *Comprehensive Vector Store Support*
+
Access to a wide range of vector databases including Azure AI Search, Chroma, Elasticsearch, Milvus, Pinecone, Qdrant, Weaviate, MongoDB Atlas, and more for scalable similarity search and AI workloads.
* *Multi-Provider Embedding Generation*
+
Generate embeddings using various model providers including Azure OpenAI, Google Vertex AI, Hugging Face, OpenAI, Einstein, and others for text, image, and multimedia content.
* *Advanced RAG Implementation*
+
Build sophisticated Retrieval Augmented Generation systems with document processing, media handling, embedding generation, and intelligent querying capabilities.
* *Flexible Storage Integration*
+
Support for multiple storage options including local storage, Azure Blob Storage, Amazon S3, and Google Cloud Storage for comprehensive data management.
* *Enterprise-Grade Performance*
+
Optimized for enterprise environments with high-performance vector operations, metadata filtering, and scalable embedding management.

== Supported Vector Stores

* *Azure AI Search* (Microsoft): Cloud-based AI-powered search with semantic search capabilities
* *AlloyDB* (Google): Fully managed relational database service with high performance and PostgreSQL compatibility
* *Chroma* (Open Source): Open-source vector database for AI and embeddings management
* *Elasticsearch* (Elastic): Scalable search engine for structured/unstructured data and analytics
* *Milvus* (Zilliz): Vector database optimized for similarity search and AI workloads
* *Amazon OpenSearch* (Amazon Web Services): Managed search service for full-text, structured data queries
* *PGVector* (Open Source): PostgreSQL extension for storing and querying vector embeddings
* *Pinecone* (Pinecone): Scalable vector database with high-speed similarity search capabilities
* *Qdrant* (Qdrant): Vector database with advanced filtering for semantic search applications
* *Weaviate* (Weaviate): Open-source, cloud-native vector database for high-dimensional data objects
* *MongoDB Atlas* (MongoDB): Fully managed, multi-cloud database service with integrated vector search
* *Ephemeral File* (LangChain4J): Ephemeral file-based vector store for testing and development

== Supported Model Providers

MuleSoft Vectors Connector supports the following model providers to generate embeddings:

* *Azure OpenAI* (Microsoft): Managed access to OpenAI models through Azure's cloud platform
* *Azure Vision AI* (Microsoft): Advanced algorithms for processing images and returning information
* *Einstein* (Salesforce): AI platform integrated into Salesforce for CRM automation and insights
* *Google Vertex AI* (Google): Generative AI models hosted on Google's advanced, global infrastructure
* *Hugging Face* (Hugging Face): Community-driven hub for machine learning models, datasets, and tools
* *Mistral AI* (Mistral): Open-weight LLMs optimized for efficiency and customization
* *Nomic* (Nomic): Tools for understanding and visualizing large datasets with embeddings and AI
* *Ollama* (Ollama): Platform offering tools and APIs for embedding-based search and AI-driven insights
* *OpenAI* (OpenAI): Developer of advanced AI models like GPT and DALL·E

== Supported Storage Options

* *Local*: Load data from application local storage
* *Azure Blob Storage*: Load data from Azure Blob Storage containers
* *Amazon S3*: Load data from Amazon S3 Buckets
* *Google Cloud Storage*: Load data from Google Cloud Storage buckets
