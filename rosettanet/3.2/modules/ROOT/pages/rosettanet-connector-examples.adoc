= RosettaNet Connector Examples 

Mule applications using Anypoint Connector for RosettaNet (RosettaNet Connector) must include a global configuration to add external libraries specific to the active security mode. Only one external libs configuration is permitted per application, so you must configure this element manually in the examples. In each of the below examples, instructions for the global configuration are provided. The global configuration is named `RosettaNet Connector External Libs` and the external libraries are specified for security mode as non-fips. If you are using security mode as fips140-2 or fips140-3, you must configure the external libraries for mule.security.model as applicable. Refer to the 
xref:release-notes::connector/rosettanet-connector-release-notes-mule-4.adoc[RosettaNet Connector Release Notes] to include specific required library versions that are compliant with the corresponding version of the connector.. 

There are two examples provided in this documentation:

xref:rosettanet-connector-single-partner-example.adoc[RosettaNet Connector Single Partner Example] : This example demonstrates how to use the single partner mode of the RosettaNet Connector to send and receive messages between a Buyer app and a Seller app. The example includes a Buyer app and a Seller app, each with its own dedicated listener and initiator configuration.

xref:rosettanet-connector-shared-example.adoc[RosettaNet Connector Shared Example] : This example demonstrates how to use the shared mode of the RosettaNet Connector to send and receive messages between multiple partners. The example includes a Buyer app and three Seller apps, each with its own dedicated listener and initiator configuration.
