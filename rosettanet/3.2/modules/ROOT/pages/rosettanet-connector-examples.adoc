= RosettaNet Connector Examples 

Mule applications using Anypoint Connector for RosettaNet (RosettaNet Connector) must include a global configuration to add external libraries specific to the active security mode. Only one external libs configuration is permitted per app, so configure this element manually in the examples. Each example includes instructions for the global configuration. The global configuration is named `RosettaNet Connector External Libs`, and the external libraries are specified for the non-FIPS security mode. If you use the fips140-2 or fips140-3 security mode, configure the external libraries to match the `mule.security.model` value. See the
xref:release-notes::connector/rosettanet-connector-release-notes-mule-4.adoc[RosettaNet Connector Release Notes] for the required library versions for each connector version.

This documentation provides two examples:

xref:rosettanet-connector-single-partner-example.adoc[RosettaNet Connector Single Partner Example]: This example demonstrates how to use the single partner mode of the RosettaNet Connector to send and receive messages between a Buyer app and a Seller app. The example includes a Buyer app and a Seller app, each with its own dedicated listener and initiator configuration.

xref:rosettanet-connector-shared-example.adoc[RosettaNet Connector Shared Example]: This example demonstrates how to use the shared mode of the RosettaNet Connector to send and receive messages between multiple partners. The example includes a Buyer app and three Seller apps, each with its own dedicated listener and initiator configuration.
