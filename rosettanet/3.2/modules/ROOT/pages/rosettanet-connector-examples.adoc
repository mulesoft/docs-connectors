= RosettaNet Connector Examples

Mule applications using Anypoint Connector for RosettaNet (RosettaNet Connector) must include one global configuration for the external libraries required by the active security mode. Each example includes instructions for configuring *RosettaNet External Libs - Non FIPS*. If you use FIPS 140-2 or FIPS 140-3 security mode, configure the external libraries to match the `mule.security.model` value. See the
xref:release-notes::connector/rosettanet-connector-release-notes-mule-4.adoc[RosettaNet Connector Release Notes] for the required library versions for each connector version.

This documentation provides two examples:

xref:rosettanet-connector-dedicated-example.adoc[RosettaNet Connector Dedicated Example]: This example demonstrates `DEDICATED` listener mode for a single Buyer app and Seller app. The Buyer uses a dedicated initiator configuration to send Purchase Orders and receive Purchase Order Confirmations. The Seller uses a dedicated responder configuration to receive Purchase Orders and send Purchase Order Confirmations.

xref:rosettanet-connector-shared-example.adoc[RosettaNet Connector Shared Example]: This example demonstrates `SHARED` listener mode for three Buyers in one app and one Seller app. Each Buyer uses dedicated initiator configurations to send Purchase Orders and receive Purchase Order Confirmations. The Seller uses one shared responder configuration to receive Purchase Orders and dedicated responder configurations to send Purchase Order Confirmations.
