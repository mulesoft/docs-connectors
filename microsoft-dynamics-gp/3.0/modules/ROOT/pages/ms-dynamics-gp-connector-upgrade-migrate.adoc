= Upgrading and Migrating Microsoft Dynamics GP Connector to 3.x

Upgrade Anypoint Connector for Microsoft Dynamics GP (Microsoft Dynamics GP Connector) from version 2.x to version 3.x.

== Supported Upgrade Paths

[%header,cols="50a,50a"]
|===
|From Version | To Version
|2.x |3.x
|===

== Changes in This Release

=== 3.0

* This connector now requires Mule runtime 4.9.0 and Java 17. Java 8 and Java 11 are no longer supported.
* The connector still calls Microsoft Dynamics GP with a direct Apache CXF client for Kerberos and SPNEGO with WS-SecureConversation. The SOAP stack moves from Apache CXF 3 on Java EE to Apache CXF 4.2.4 on Jakarta. This upgrade addresses CVE-2026-49875, CVE-2026-78384, CVE-2026-97791, and CVE-2026-97468. Web Services Security is upgraded to 4.0.2, and Apache XML Security (Santuario) is upgraded to 4.0.4. The Jakarta SOAP stack includes Jakarta XML Binding 4.0.2, Jakarta XML Web Services 4.0.2, Jakarta XML SOAP 3.0.2, the Jakarta annotation API 2.1.1, the JAXB runtime 4.0.5, and the SAAJ implementation 3.0.6. Apache Xerces is upgraded from version 2.12.0-stripped to version 2.12.2.
* Generated sources and WSDL bindings now use Jakarta XML packages. Operation names, the XML namespace, and the `dynamicsgp` configuration prefix are unchanged.
* The xref:ms-dynamics-gp-connector-reference.adoc#config[Default Configuration] Advanced tab now includes optional *Timeout unit*, *Connection timeout*, and *Read timeout* fields. Each operation can override these values in the *Timeout Override* group on the Advanced tab with *Timeout Unit*, *Connection Timeout*, and *Read Timeout*. An override applies when you set *Connection Timeout* or *Read Timeout*. When you don't set those values, the Kerberos Authentication *Timeout Configuration* values remain in effect.
* Failures that were reported as `DYNAMICSGP:UNKNOWN` are reported as `DYNAMICSGP:DYNAMICSGP_INTERNAL`. `DYNAMICSGP:DYNAMICSGP_INTERNAL` and `DYNAMICSGP:XML_PARSING` remain children of `ANY`, so a condition on `ANY` still matches. A handler that names `DYNAMICSGP:UNKNOWN` doesn't match this release.

== Upgrade Prerequisites

Before you perform the upgrade, you must:

. Create a backup of your files, data, and configuration in case you need to restore to the previous version.
. Ensure that your environment meets the version 3.x requirements, including Java 17 and Mule runtime 4.9.0 or later.
. If an error handler names `DYNAMICSGP:UNKNOWN`, update it to `DYNAMICSGP:DYNAMICSGP_INTERNAL`. A condition on `ANY` still matches `DYNAMICSGP:DYNAMICSGP_INTERNAL` and `DYNAMICSGP:XML_PARSING`.
. Install Microsoft Dynamics GP Connector 3.x to replace the connector operations that were previously included in version 2.x.

== Upgrade Steps

Follow these steps to perform the upgrade from Microsoft Dynamics GP Connector 2.x to Microsoft Dynamics GP Connector 3.x:

. In Anypoint Studio, create a Mule project.
. In the Mule Palette view, click *Search in Exchange*.
. In the *Add Dependencies to Project* window, enter `Microsoft Dynamics GP` in the search field.
. In the *Available modules* section, select *Microsoft Dynamics GP Connector* and click *Add*.
. Click *Finish*.
. Verify that the `mule-microsoft-dynamics-gp-connector` dependency version is `3.x.x` in the `pom.xml` file, where `x.x` is the minor release and patch version number. For example, if you are upgrading to version 3.0, the dependency version in the `pom.xml` file should be `3.0.0`.

Studio upgrades the connector automatically.

== Verify the Upgrade

After you install the latest version of the connector, follow these steps to verify the upgrade:

. In Studio, verify that there are no errors in the *Problems* or *Console* views.
. Check the project `pom.xml` file and verify that there are no problems.
. Test the connection and verify that the operations work.
. If the application handles `DYNAMICSGP:UNKNOWN`, confirm that the handler now uses `DYNAMICSGP:DYNAMICSGP_INTERNAL`.

== Troubleshooting

If there are problems with caching the parameters and caching the metadata, try restarting Studio.

== Revert the Upgrade

If it is necessary to revert to the previous version of Microsoft Dynamics GP Connector, change the `mule-microsoft-dynamics-gp-connector` dependency version in the project's `pom.xml` file to the previous version.

You must update the project's `pom.xml` file in Anypoint Studio.
