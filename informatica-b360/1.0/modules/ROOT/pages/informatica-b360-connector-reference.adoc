= Informatica Business 360 Connector 1.0 Reference

Anypoint Connector for Informatica Business 360 (Informatica B360 Connector) enables you to connect to the Informatica Business 360 (MDM) REST API.

[[Search]]
== Search
`<informatica-b360:search>`

Searches for business entity records using full-text or field-based queries with automatic pagination. Results are returned one record at a time as the Mule runtime iterates over the result set; pages are fetched transparently on demand.

Use the `search` parameter for full-text queries with wildcards (`*`, `~`, `&&`, `||`) or the `fields` parameter for field-specific value lookups. The two parameters are mutually exclusive.

[[SearchMatchV1]]
== Search Match V1
`<informatica-b360:search-match-v1>`

Performs ML-based fuzzy matching to find source records similar to the provided search record. The match engine uses blocking fields defined in the match model to identify candidates, then scores each candidate against the search record. All matching results are returned in a single response.

The search record must include at least one blocking field defined in the match model. Without a blocking field, the API returns an error.

[[SearchMatchV2]]
== Search Match V2
`<informatica-b360:search-match-v2>`

Performs ML-based fuzzy matching to find master records similar to the provided search record. Unlike Search Match V1, this operation matches directly against master records rather than source records, returning the consolidated master record directly. This can provide better performance and more relevant results. All matching results are returned in a single response.

NOTE: Search Match V2 may not be enabled on all B360 tenants. Tenants without V2 support return an error.
