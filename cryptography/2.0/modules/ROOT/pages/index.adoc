= Cryptography Module

Cryptography Module provides cryptography capabilities to a Mule application. Its main features include:

* Symmetric encryption and decryption of messages.
* Asymmetric encryption and decryption of messages.
* Message signing and signature validation of signed messages.

The module supports these strategies to encrypt and sign your messages:

* xref:cryptography-module-jce.adoc[JCE]: Utilize the broader cryptography capabilities of Java Cryptography Extension.
* xref:cryptography-module-pgp.adoc[PGP]: Encrypt and sign using Pretty Good Privacy.
* xref:cryptography-module-xml.adoc[XML]: Encrypt and sign XML documents and their elements.


Additionally, the module offers two general operations to calculate and validate stream checksums.
