= Shopify Connector - Additional Configuration Information - Mule 4

After you complete basic Shopify Connector configuration, you can perform additional configuration tasks.

== Configure Shopify Metafield Values 

To configure Shopify metafield values with Shopify Connector, add a custom query parameter to the operation. Shopify Connector doesn't support creating new metafields; however, you can modify existing metafields using the predefined operations that support them.

For example, use the *Product Update* operation to get and update Shopify metafield values:

. In the *Advanced* tab of the *Product Update* operation configuration, in the *Query Parameters* field, select `Edit inline`.
. Add the metafield in the *Key* field and the https://shopify.dev/docs/api/admin-rest/2024-10/resources/order#put-orders-order-id[API details] in the *Value* field.
