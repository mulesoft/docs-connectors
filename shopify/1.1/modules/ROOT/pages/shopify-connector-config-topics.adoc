= Shopify Connector - Additional Configuration Information - Mule 4

After you complete basic Shopify Connector configuration, you can perform additional configuration tasks.

== Get and Update Shopify Metafield Values 

To get and update Shopify metafield values using Shopify Connector, add a custom query parameter to the *Product Update* operation.

In the *Advanced* tab of the *Product Update* operation configuration, in the *Query Parameters* field, select `Edit inline`. Then, add the metafield as *Key* and the https://shopify.dev/docs/api/admin-rest/2024-10/resources/order#put-orders-order-id[API details] as *Value*.
