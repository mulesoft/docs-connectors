This is the dependency information for MuleSoft WebCrawler Connector when installing from Maven Central:

[source,xml,linenums]
----
<dependency>
    <groupId>com.mulesoft.connectors</groupId>
    <artifactId>mule4-webcrawler-connector</artifactId>
    <version>x.x.x</version>
    <classifier>mule-plugin</classifier>
</dependency>
----

Replace `x.x.x` with the version that you are using.
