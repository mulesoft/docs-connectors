= Configuring Page Operations

Configure the *[Page] Get Content*, *[Page] Download Document*, *[Page] Download Image*, and *[Page] Get Insights* operations.

== Configure the [Page] Get Content Operation

The *[Page] Get Content* operation retrieves the content of a specified web page in TEXT, HTML, or MARKDOWN format. Optionally target specific HTML tags via the Tag list parameter.

To configure the *[Page] Get Content* operation:

include::connectors::partial$t-configure-operations.adoc[]
* *Page URL*
+
The URL of the page to retrieve content from.

* *Output format*
+
Format of the extracted content. Select TEXT, HTML, or MARKDOWN. Default is TEXT.

* *Tag list*
+
List of HTML tags for which content must be retrieved. If specified, only content within the listed tags is returned.

* *Javascript*
+
JavaScript code to execute on page load after wait and before shadow DOM extraction. Use this to interact with the page (for example, click buttons or expand accordions) before content is extracted.

=== Page Load Options

* *Wait on page load*
+
The time to wait on page load, in the time unit selected below.

* *Wait on page load unit*
+
Time unit for the page-load wait.

=== WebDriver Options (Remote WebDriver only)

These options apply only when using the Remote WebDriver connection type:

* *Wait for XPath*
+
The XPath to wait for before proceeding with content extraction.

* *Extract Shadow DOM*
+
If true, extracts the Shadow DOM content.

* *Shadow Host(s) XPath*
+
Shadow host(s) to extract by XPath. If not set, the whole Shadow DOM is extracted.

=== XML Configuration

This is the XML for this operation:

[source,xml,linenums]
----
<ms-webcrawler:page-content
    config-ref="MuleSoft_WebCrawler_Config"
    doc:name="[Page] Get content"
    doc:id="8f436a64-1795-42a0-9fe7-69be66db235b"
    url="#[payload.url]"
    outputFormat="MARKDOWN"
    waitOnPageLoad="5"
    waitForXPath="//results"
    extractShadowDom="true"
    shadowHostXPath="//results"/>
----

=== Output Configuration

This operation responds with a JSON payload. This is an example response:

[source,json]
----
{
    "title": "Example Page Title",
    "url": "https://example.com/page",
    "content": "The full text content of the page..."
}
----

* `title`
+
The page title.
* `url`
+
The page URL.
* `content`
+
The extracted content in the specified output format.

== Configure the [Page] Download Document Operation

The *[Page] Download Document* operation downloads documents from a web page or from a direct document URL and saves them to the specified location.

To configure the *[Page] Download Document* operation:

include::connectors::partial$t-configure-operations.adoc[]
* *Page or document URL*
+
The web page URL containing documents to download, or a direct document link.

* *Download location*
+
Filesystem path where downloaded documents are saved.

* *Max number of documents*
+
Maximum number of documents to download. Default 0 means no limit.

* *Javascript*
+
JavaScript code to execute on page load after wait and before shadow DOM extraction.

=== Page Load Options

* *Wait on page load*
+
The time to wait on page load, in the time unit selected below.

* *Wait on page load unit*
+
Time unit for the page-load wait.

=== WebDriver Options (Remote WebDriver only)

These options apply only when using the Remote WebDriver connection type:

* *Wait for XPath*
+
The XPath to wait for before proceeding with content extraction.

* *Extract Shadow DOM*
+
If true, extracts the Shadow DOM content.

* *Shadow Host(s) XPath*
+
Shadow host(s) to extract by XPath. If not set, the whole Shadow DOM is extracted.

=== XML Configuration

This is the XML for this operation:

[source,xml,linenums]
----
<ms-webcrawler:page-download-document
    config-ref="MuleSoft_WebCrawler_Config"
    doc:name="[Page] Download document"
    doc:id="426d217d-74c5-4c9d-9bdb-74f075fc1f26"
    url="#[payload.url]"
    downloadPath="#[payload.downloadLocation]"
    maxDocumentNumber="50"/>
----

=== Output Configuration

This operation responds with a JSON array. Each element contains information about a downloaded document. This is an example response:

[source,json]
----
[
    {
        "fileName": "versioning-back-support-policy.pdf",
        "mimeType": "application/pdf",
        "url": "https://www.example.com/content/documents/policy.pdf"
    }
]
----

* `fileName`
+
The name of the downloaded file.
* `mimeType`
+
The MIME type of the downloaded file.
* `url`
+
The original URL of the document.

== Configure the [Page] Get Insights Operation

The *[Page] Get Insights* operation fetches analytical data about a web page including word count, element or tag counts (H1–H5, DIV, P), link structures (internal, external, reference), and image links. Use these insights to customize subsequent crawling operations.

To configure the *[Page] Get Insights* operation:

include::connectors::partial$t-configure-operations.adoc[]
* *Page URL*
+
The URL of the page to analyze.

* *Tag list*
+
List of HTML tags for which content must be retrieved.

* *Javascript*
+
JavaScript code to execute on page load after wait and before shadow DOM extraction.

=== Page Load Options

* *Wait on page load*
+
The time to wait on page load, in the time unit selected below.

* *Wait on page load unit*
+
Time unit for the page-load wait.

=== WebDriver Options (Remote WebDriver only)

These options apply only when using the Remote WebDriver connection type:

* *Wait for XPath*
+
The XPath to wait for before proceeding with content extraction.

* *Extract Shadow DOM*
+
If true, extracts the Shadow DOM content.

* *Shadow Host(s) XPath*
+
Shadow host(s) to extract by XPath. If not set, the whole Shadow DOM is extracted.

=== XML Configuration

This is the XML for this operation:

[source,xml,linenums]
----
<ms-webcrawler:page-insights
    config-ref="MuleSoft_WebCrawler_Config"
    doc:name="[Page] Get insights"
    doc:id="08dd9627-5220-41df-a7cf-869bff4eee91"
    url="#[payload.url]"/>
----

=== Output Configuration

This operation responds with a JSON payload containing page statistics and link details. This is an example response:

[source,json]
----
{
    "pageStats": {
        "div": 36,
        "p": 6,
        "reference": 0,
        "internal": 7,
        "external": 2,
        "images": 4,
        "wordCount": 147,
        "h1": 1,
        "h2": 0,
        "h3": 4,
        "h4": 0,
        "h5": 0
    },
    "links": {
        "reference": [],
        "internal": ["https://example.com/docs", "https://example.com/about"],
        "external": ["https://github.com/example"],
        "images": ["https://example.com/images/logo.png"],
        "documents": [],
        "iframe": []
    },
    "title": "Example Page",
    "url": "https://example.com/"
}
----

* `pageStats` - Counts of HTML elements and page metrics.

** `div`, `p`, `h1` through `h5` - Counts of the respective HTML elements.
** `reference`, `internal`, `external` - Counts of reference, internal, and external links.
** `images` - Count of images on the page.
** `wordCount` - Total word count of the page content.

* `links` - Categorized lists of URLs found on the page.

** `reference` - Reference links (anchors).
** `internal` - Internal links to the same domain.
** `external` - External links to other domains.
** `images` - Image URLs.
** `documents` - Document URLs.
** `iframe` - Iframe URLs.

* `title` - The page title.
* `url` - The page URL.
