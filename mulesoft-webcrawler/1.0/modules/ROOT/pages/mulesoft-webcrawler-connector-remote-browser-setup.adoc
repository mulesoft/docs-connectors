== Overview

MuleSoft WebCrawler Connector's Remote WebDriver connection requires a remote browser to render JavaScript-heavy pages, single-page applications, and Shadow DOM content before scraping.

MuleSoft doesn't provide, host, or manage a remote browser. You bring your own Chromium-based remote WebDriver endpoint (Chrome, Chromium, or Edge) and are responsible for provisioning, securing, and maintaining it. This page describes common ways to set up your own endpoint.
