= NetSuite REST Connector 1.1 - Additional Configuration Information

NetSuite REST Connector provides detailed configuration information for each operation and source type. Select the category you want to configure.

Every operation accepts *Custom Headers* and *Custom Query Parameters*. A custom header overrides a default header with the same name, and a custom query parameter overrides a default query parameter with the same name. The connector still controls `Authorization`, `Content-Type`, and `Prefer`.
