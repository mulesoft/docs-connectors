= NetSuite REST Connector 1.1 - Additional Configuration Information

NetSuite REST Connector provides detailed configuration information for each operation and source type. Select the category you want to configure.

[[request-defaults]]
== Request Headers, Query Parameters, and Proxy

Connection *Default Headers* and *Query Parameters* are added to every NetSuite REST request, including polling-source requests. Each operation accepts *Custom Headers* and *Custom Query Parameters*. A custom header replaces a *Default Headers* entry with the same name, and a custom query parameter replaces a *Query Parameters* entry with the same name. Polling sources don't have these operation fields.

The connector always sends `Authorization`. It sends `Content-Type` when the operation includes a body. It sends `Prefer: respond-async` on batch operations and `Prefer: transient` on SuiteQL and change-tracking requests. When an operation sets `Accept`, including *Initialize Record (Transform)*, *Transform Record*, *Create Form*, *Edit Form*, *Get Select Value*, and the metadata catalog operations, that value is used. These connector-set headers replace a custom or default header with the same name.

Set the HTTP proxy on the connection *Proxy* tab. *Host* and *Port* must both be set, or both left empty. If only one is set, the connector fails with `Proxy Host and Port must both be set, or both left empty`. *Port* must be between 1 and 65535. The proxy is used for NetSuite REST calls and for the OAuth token request. For the field descriptions, see xref:netsuite-rest-connector-reference.adoc#Config_Connection[OAuth 2.0 Client Credentials (JWT Bearer)].

[source,xml,linenums]
----
<ms-netsuite-rest:config name="Config">
    <ms-netsuite-rest:connection
        accountId="${netsuite.accountId}"
        clientId="${netsuite.clientId}"
        certificateId="${netsuite.certificateId}"
        privateKey="${secure::netsuite.privateKey}"
        signatureAlgorithm="ES512"
        host="${netsuite.proxy.host}"
        port="${netsuite.proxy.port}"
        username="${netsuite.proxy.username}"
        password="${secure::netsuite.proxy.password}"
        nonProxyHosts="localhost,127.0.0.1">
        <ms-netsuite-rest:default-headers>
            <ms-netsuite-rest:default-header key="X-Example-Header" value="from-connection"/>
        </ms-netsuite-rest:default-headers>
        <ms-netsuite-rest:default-query-params>
            <ms-netsuite-rest:default-query-param key="exampleParam" value="from-connection"/>
        </ms-netsuite-rest:default-query-params>
    </ms-netsuite-rest:connection>
</ms-netsuite-rest:config>

<ms-netsuite-rest:get-server-time
    config-ref="Config"
    doc:name="Get Server Time"
    customHeaders='#[{"X-Example-Header": "from-operation"}]'
    customQueryParams='#[{"exampleParam": "from-operation"}]'/>
----
