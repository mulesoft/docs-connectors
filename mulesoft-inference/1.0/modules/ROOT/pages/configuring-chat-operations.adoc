= Configuring Chat Operations

== Configure the Chat Answer Prompt Operation

The *Chat answer prompt* operation is a simple prompt request operation to the configured inference provider. It uses a plain text prompt as input and responds with a plain text answer.

To configure the *Chat answer prompt* operation:

. Select the operation on the Anypoint Code Builder or Studio canvas.
. In the *General* properties tab for the operation, enter plain text for the *Prompt*.

This is the XML configuration for this operation:

[source,xml]
----
<ms-inference:chat-answer-prompt 
  doc:name="Chat answer prompt" 
  doc:id="8ba9d534-f801-4ac7-8a31-11462fc5204b" 
  config-ref="MuleSoft_Inference_Configuration" 
  prompt="#[payload.prompt]"  
/>
----

[[output-config]]
=== Output Configuration

This operation responds with a JSON payload containing the main inference provider response. 

This is an example response:

[source,json]
----
{
    "response": "The capital of Switzerland is Bern. It's known for its well-preserved medieval old town, which is a UNESCO World Heritage site. Bern became the capital of Switzerland in 1848. The Swiss parliament, the Federal Assembly, is located in Bern."
}
----

The operation also returns attributes that aren't within the main JSON payload, which include information about token usage and provider details, for example:

[source,json]
----
{
  "tokenUsage": {
      "outputCount": 9,
      "totalCount": 18,
      "inputCount": 9
  },
  "additionalAttributes": {
      "provider": "anthropic",
      "model": "claude-3-sonnet",
      "responseTime": 1250
  }
}
----

== Configure the Chat Completion Operation

The *Chat completion* operation provides advanced chat capabilities with support for conversation context, system messages, and structured responses from your configured inference provider.

To configure the *Chat completion* operation:

include::connectors::partial$t-configure-operations.adoc[]
* *Messages*
+
Array of message objects containing the conversation history. Each message should include role (system, user, assistant) and content.
* *System Message*
+
Optional system message to set the behavior and context for the inference provider.
* *Max Tokens*
+
Maximum number of tokens to generate in the response.
* *Temperature*
+
Controls randomness in the response. Range from 0.0 (deterministic) to 1.0 (more creative).

This is the XML configuration for this operation:

[source,xml]
----
<ms-inference:chat-completion
  doc:name="Chat completion"
  doc:id="7e62e70e-eff7-4080-bb20-3d162bb84c39"
  config-ref="MuleSoft_Inference_Configuration"
  messages="#[payload.messages]"
  systemMessage="#[payload.systemMessage]"
  maxTokens="#[payload.maxTokens]"
  temperature="#[payload.temperature]">
</ms-inference:chat-completion>
----

=== Output Configuration

This operation responds with a JSON payload containing the main inference provider response, with additional metadata stored in attributes.

This is an example response:

[source,json]
----
{
    "response": "I can help you with that. Based on your requirements, I recommend the following approach..."
}
----

The operation also returns attributes that aren't within the main JSON payload, which include information about token usage and provider details, for example:

[source,json]
----
{
  "tokenUsage": {
    "outputCount": 42,
    "totalCount": 128,
    "inputCount": 86
  },
  "additionalAttributes": {
    "provider": "openai",
    "model": "gpt-4-turbo",
    "responseTime": 2100,
    "finishReason": "stop"
  }
}
----
