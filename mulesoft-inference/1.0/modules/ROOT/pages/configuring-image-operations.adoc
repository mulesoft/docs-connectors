= Configuring Image Operations

== Configure the Read Image Operation

The *Read Image* operation allows you to analyze and extract information from images using vision-enabled inference providers. You can provide images via URL or Base64 encoded data.

To configure the *Read Image* operation:

include::connectors::partial$t-configure-operations.adoc[]
* *Image Source*
+
Specify how the image is provided:
** *URL*: Direct URL to the image
** *Base64*: Base64 encoded image data
* *Image Data*
+
The image URL or Base64 encoded string, depending on the selected source type.
* *Prompt*
+
The text prompt describing what you want to analyze or extract from the image.
* *Max Tokens*
+
Maximum number of tokens to generate in the response.

This is the XML configuration for this operation:

[source,xml]
----
<ms-inference:read-image
  doc:name="Read image"
  doc:id="8ba9d534-f801-4ac7-8a31-11462fc5204b"
  config-ref="MuleSoft_Inference_Configuration"
  imageSource="#[payload.imageSource]"
  imageData="#[payload.imageData]"
  prompt="#[payload.prompt]"
  maxTokens="#[payload.maxTokens]">
</ms-inference:read-image>
----

=== Output Configuration

This operation responds with a JSON payload containing the analysis results from the vision-enabled inference provider.

This is an example response:

[source,json]
----
{
    "response": "This image shows a modern office building with glass facades. The building appears to be approximately 15 stories tall with a contemporary architectural design. There are several people walking near the entrance, and the surrounding area includes landscaped gardens and a parking area."
}
----

The operation also returns attributes with token usage and provider information:

[source,json]
----
{
  "tokenUsage": {
      "outputCount": 45,
      "totalCount": 78,
      "inputCount": 33
  },
  "additionalAttributes": {
      "provider": "openai",
      "model": "gpt-4-vision-preview",
      "imageSource": "url",
      "responseTime": 3200
  }
}
----

== Configure the Image Generation Operation

The *Image Generation* operation creates images based on text descriptions using image generation inference providers.

To configure the *Image Generation* operation:

include::connectors::partial$t-configure-operations.adoc[]
* *Prompt*
+
Detailed text description of the image you want to generate.
* *Size*
+
Image dimensions (e.g., "1024x1024", "512x512").
* *Quality*
+
Image quality setting (e.g., "standard", "hd").
* *Style*
+
Optional style parameter for the generated image.
* *Number of Images*
+
Number of images to generate (typically 1-4).

This is the XML configuration for this operation:

[source,xml]
----
<ms-inference:image-generation
  doc:name="Image generation"
  doc:id="7e62e70e-eff7-4080-bb20-3d162bb84c39"
  config-ref="MuleSoft_Inference_Configuration"
  prompt="#[payload.prompt]"
  size="#[payload.size]"
  quality="#[payload.quality]"
  style="#[payload.style]"
  numberOfImages="#[payload.numberOfImages]">
</ms-inference:image-generation>
----

=== Output Configuration

This operation responds with a JSON payload containing the generated image URLs or Base64 data.

This is an example response:

[source,json]
----
{
    "images": [
        {
            "url": "https://example.com/generated-image-1.png",
            "revisedPrompt": "A photorealistic image of a modern office building with glass facades, surrounded by landscaped gardens"
        }
    ]
}
----

The operation also returns attributes with generation details:

[source,json]
----
{
  "additionalAttributes": {
      "provider": "openai",
      "model": "dall-e-3",
      "size": "1024x1024",
      "quality": "hd",
      "numberOfImages": 1,
      "responseTime": 8500
  }
}
----

== Provider Support Notes

* *Image Reading*: Supported by Anthropic, GitHub Models, Google Vertex AI, Groq AI, Hugging Face, Mistral, OpenAI, OpenAI Compatible Endpoints, OpenRouter, Portkey, XAI, and Azure AI Foundry.
* *Image Generation*: Supported by Hugging Face, OpenAI, Stability AI, and XAI.
* *Ollama*: Supports Base64 image input only for image reading operations.
* Some providers may have "Coming soon" status for image operations.
