= Configuring Custom Model Operations

Configure the *CUSTOM Model Details* and *CUSTOM Models List* operations.

== Configure the CUSTOM Model Details Operation

The *CUSTOM Model Details* operation retrieves additional details for a specific custom model that you have created or fine-tuned in Amazon Bedrock.

To configure the *CUSTOM Model Details* operation:

include::connectors::partial$t-configure-operations.adoc[]
* *Model name*
+
The name of the custom model. You can select any custom model that you have created.

* *Region*
+
The AWS region.

This is the XML for this operation:

[source,xml,linenums]
----
<mac-bedrock:
  custom-model-details 
  doc:name="Custom model details" 
  doc:id="abcd1234-5678-90ab-cdef-1234567890ab" 
  config-ref="AWS" 
  modelName="#[payload.modelName]"
/>
----

=== Output Configuration

This operation responds with a JSON payload. This is an example response:

[source,json]
----
{
    "modelName": "my-custom-model",
    "modelArn": "arn:aws:bedrock:us-east-1:123456789012:custom-model/my-custom-model",
    "baseModelArn": "arn:aws:bedrock:us-east-1::foundation-model/amazon.titan-text-express-v1",
    "customizationType": "FINE_TUNING",
    "modelKmsKeyArn": null,
    "hyperParameters": {
        "epochCount": "2",
        "batchSize": "8",
        "learningRate": "0.00001"
    },
    "trainingDataConfig": {
        "s3Uri": "s3://my-bucket/training-data/"
    },
    "creationTime": "2024-01-15T10:30:00Z"
}
----

* `modelName`: The name of the custom model.
* `modelArn`: The Amazon Resource Name (ARN) for the custom model.
* `baseModelArn`: The ARN of the base foundation model used for customization.
* `customizationType`: The type of customization (for example, `FINE_TUNING` or `CONTINUED_PRE_TRAINING`).
* `modelKmsKeyArn`: The ARN of the KMS key used for encryption, if applicable.
* `hyperParameters`: The hyperparameters used during model training.
* `trainingDataConfig`: The configuration for training data, including the S3 URI.
* `creationTime`: When the custom model was created.

== Configure the CUSTOM Models List Operation

The *CUSTOM Models List* operation retrieves a list of all custom models that you have created or fine-tuned in Amazon Bedrock for the specified region.

To configure the *CUSTOM Models List* operation:

include::connectors::partial$t-configure-operations.adoc[]
* *Region*
+
The AWS region.

This is the XML for this operation:

[source,xml,linenums]
----
<mac-bedrock:
  custom-models-list 
  doc:name="Custom models list" 
  doc:id="efgh5678-1234-abcd-5678-90abcdef1234" 
  config-ref="AWS"
/>
----

=== Output Configuration

This operation responds with a JSON payload. This is an example response:

[source,json]
----
[
    {
        "modelName": "my-custom-model-1",
        "modelArn": "arn:aws:bedrock:us-east-1:123456789012:custom-model/my-custom-model-1",
        "baseModelArn": "arn:aws:bedrock:us-east-1::foundation-model/amazon.titan-text-express-v1",
        "customizationType": "FINE_TUNING",
        "creationTime": "2024-01-15T10:30:00Z"
    },
    {
        "modelName": "my-custom-model-2",
        "modelArn": "arn:aws:bedrock:us-east-1:123456789012:custom-model/my-custom-model-2",
        "baseModelArn": "arn:aws:bedrock:us-east-1::foundation-model/anthropic.claude-v2",
        "customizationType": "CONTINUED_PRE_TRAINING",
        "creationTime": "2024-02-20T14:45:00Z"
    }
]
----

* `modelName`: The name of the custom model.
* `modelArn`: The Amazon Resource Name (ARN) for the custom model.
* `baseModelArn`: The ARN of the base foundation model used for customization.
* `customizationType`: The type of customization (for example, `FINE_TUNING` or `CONTINUED_PRE_TRAINING`).
* `creationTime`: When the custom model was created.
