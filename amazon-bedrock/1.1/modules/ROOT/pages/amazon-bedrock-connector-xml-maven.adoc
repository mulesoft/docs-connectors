== Add a Namespace for the Connector

Paste the following code inside the `mule` tag in the header of your configuration XML:

[source,xml,linenums]
----
xmlns:ms-bedrock="http://www.mulesoft.org/schema/mule/ms-bedrock"
----

Add the following pair to the `xsi:schemaLocation` attribute:

[source,xml,linenums]
----
http://www.mulesoft.org/schema/mule/ms-bedrock
http://www.mulesoft.org/schema/mule/ms-bedrock/current/mule-ms-bedrock.xsd
----

This example shows the connector namespace and schema location in a Mule configuration:

[source,xml,linenums]
----
<mule xmlns:ms-bedrock="http://www.mulesoft.org/schema/mule/ms-bedrock"
  xmlns="http://www.mulesoft.org/schema/mule/core"
  xmlns:doc="http://www.mulesoft.org/schema/mule/documentation"
  xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
  xsi:schemaLocation="
    http://www.mulesoft.org/schema/mule/core
    http://www.mulesoft.org/schema/mule/core/current/mule.xsd
    http://www.mulesoft.org/schema/mule/ms-bedrock
    http://www.mulesoft.org/schema/mule/ms-bedrock/current/mule-ms-bedrock.xsd">
</mule>
----
