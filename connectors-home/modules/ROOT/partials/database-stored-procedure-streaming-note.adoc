// Used in Database Connector stored procedure documentation

[NOTE]
====
Streaming of stored procedure result sets applies only when the JDBC driver supports multiple open result sets (`DatabaseMetaData#supportsMultipleOpenResults()` returns `true`). If the driver doesn't support this capability (for example, the Microsoft SQL Server JDBC driver), Database Connector reads every result set fully into memory before the operation returns. Large result sets can cause high memory usage.
====
