// Used in Einstein AI Connector configuration topics for operation configuration Additional Properties 

. In *Additional properties*, enter these values:
* *Model name*
+
Select the model name. The default is `OpenAI GPT 3.5 Turbo`.
* *Probability*
+
Enter the probability of the model staying accurate. The default is `0.8`.
*Locale*
+
Enter the localization information, which can include the default locale, input locale(s), and expected output locale(s). The default is `en_US`.
