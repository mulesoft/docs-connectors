Before you deploy the app:

* Add the `-Dmule.http.service.implementation=NETTY` property to your app in Runtime Manager for CloudHub and Runtime Fabric deployments. For more information, see xref:cloudhub-2::ch2-deploy.adoc[] and xref:runtime-fabric::deploy-to-runtime-fabric.adoc[].
+
For hybrid deployments, add the property to whatever you use to start Mule apps. For more information, see xref:runtime-manager::deploying-to-your-own-servers.adoc[].
