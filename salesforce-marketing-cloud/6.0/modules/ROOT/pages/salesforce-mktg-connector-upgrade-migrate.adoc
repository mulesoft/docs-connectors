= Upgrading and Migrating Salesforce Marketing Cloud Connector to 6.x
:page-aliases: connectors::salesforce/salesforce-mktg-connector-upgrade-migrate.adoc

Upgrade Anypoint Connector for Salesforce Marketing Cloud (Salesforce Marketing Cloud Connector) from version 5.x to version 6.x.

== Supported Upgrade Paths

[%header,cols="50a,50a"]
|===
|From Version | To Version
|5.x |6.x
|===

== Changes in This Release

=== 6.0

* Connector operations are unchanged from version 5.x.
* Spring is no longer included with the connector. Applications that used Spring classes from this connector must provide Spring themselves.
* SOAP requests now use Mule SOAP engine 3.0.3 and Apache CXF 4.2.4.
* These libraries are upgraded:

** The `gson` library is upgraded to version 2.15.0.
** The `jackson-databind`, `jackson-core`, `jackson-dataformat-xml`, `jackson-datatype-jsr310`, and `jackson-module-jakarta-xmlbind-annotations` libraries are upgraded to version 2.23.0.
** The `jetty-http`, `jetty-security`, `jetty-server`, and `jetty-util` libraries are upgraded to version 12.1.14.
** The `guava` library is upgraded to version 33.8.0-jre to address reported security vulnerabilities.
** The `commons-collections4` library is upgraded to version 4.6.0.
** The `asm` library is upgraded to version 9.11.1.
** The `jakarta.annotation-api` library is upgraded to version 3.0.0.
** The `jaxb-runtime` library remains at version 4.0.9 to address reported security vulnerabilities.

== Requirements

Ensure your system meets these compatibility requirements before you upgrade:

|===

|Java |17
|===

== Upgrade Prerequisites

Before you perform the upgrade, you must:

. Create a backup of your files, data, and configuration in case you must restore to the previous version.
. If your application uses Spring classes from this connector, add Spring to the application. Version 6.x doesn't include Spring.
. Install Salesforce Marketing Cloud Connector 6.x.x.

== Upgrade Steps

Follow these steps to perform the upgrade from Salesforce Marketing Cloud Connector 5.x.x to Salesforce Marketing Cloud Connector 6.x.x:

. In Anypoint Studio, create a Mule project.
. In the *Mule Palette* view, click *Search in Exchange*.
. In the *Add Dependencies to Project* window, enter `Salesforce Marketing Cloud` in the search field.
. In the *Available modules* section, select *Salesforce Marketing Cloud Connector* and click *Add*.
. Click *Finish*.
. Verify that the `mule-sfdc-marketing-cloud-connector` dependency version is `6.x.x` in the `pom.xml` file, where the first `x` is the minor release number and the second `x` is the patch release number.

Studio upgrades the connector automatically.

== Verify the Upgrade

After you install the latest version of the connector, follow these steps to verify the upgrade:

. In Studio, verify that there are no errors in the *Problems* or *Console* views.
. Check the project `pom.xml` file and verify that there are no problems.
. Test the connection and verify that the operations work.

== Troubleshooting

If there are problems with caching the parameters or caching the metadata, try restarting Studio.

== Revert the Upgrade

If it is necessary to revert to the previous version of Salesforce Marketing Cloud Connector, change the `mule-sfdc-marketing-cloud-connector` dependency version `6.x.x` in the project's `pom.xml` file to the previous version.
