= Upgrading and Migrating Microsoft Dynamics NAV Connector to Version 4.0

Upgrade Anypoint Connector for Microsoft Dynamics NAV (Microsoft Dynamics NAV Connector) from version 3.x to version 4.x.

== Supported Upgrade Paths

[%header,cols="50a,50a"]
|===
|From Version | To Version
|3.x |4.x
|===

== Changes in This Release

=== 4.0

* This connector is now compatible with Java 17 only. 
* SOAP bindings now use Jakarta XML packages, instead of Java EE packages. Applications that depend on `javax` SOAP APIs or Apache CXF 3 behavior must be re-verified. Operation names and the `nav` configuration prefix are unchanged.
* The NTLM and OAuth connection types now include optional *Response Timeout* and *Response Timeout Unit* fields. The default response timeout is 5000 milliseconds.
* The JAXB-XJC external library for the NTLM and OAuth connection types is now version 4.0.9 for Mule runtime 4.9.0 and Java 17.
* These libraries are upgraded to address reported security vulnerabilities:

** The Apache CXF library is upgraded to version 4.2.4.
** The JAXB runtime and XJC libraries are upgraded to version 4.0.9.
** The Jakarta XML Bind API is upgraded to version 4.0.5.
** The Apache Commons Lang library is upgraded to version 3.21.0.

* These libraries are added to address reported security vulnerabilities:

** The Jakarta XML Web Services API is added at version 4.0.3.
** The Jakarta XML SOAP API is added at version 3.0.2.
** The Jakarta JWS API is added at version 3.0.0.
** The SAAJ implementation is added at version 3.0.6.
** The Bouncy Castle libraries are added at version 1.86.

== Upgrade Prerequisites

Before you perform the upgrade, you must:

. Create a backup of your files, data, and configuration in case you need to restore to the previous version.
. Ensure that your environment meets the version 4.x requirements, including Java 17 and Mule runtime 4.9.0 or later.
. Re-verify applications that depend on `javax` SOAP APIs or Apache CXF 3 behavior.
. Update the JAXB-XJC external library to version 4.0.9 for the NTLM and OAuth connection types.
. Install Microsoft Dynamics NAV Connector 4.x to replace the connector operations that were previously included in version 3.x.

== Upgrade Steps

Follow these steps to perform the upgrade from Microsoft Dynamics NAV Connector 3.x to Microsoft Dynamics NAV Connector 4.x:

. In Anypoint Studio, create a Mule project.
. In the Mule Palette view, click *Search in Exchange*.
. In the *Add Dependencies to Project* window, enter `dynamics nav` in the search field.
. In the *Available modules* section, select *Microsoft Dynamics NAV* and click *Add*.
. Click *Finish*.
. Verify that the `mule-microsoft-dynamics-nav-connector` dependency version is `4.x.x` in the `pom.xml` file, where `x.x` is the minor release and patch version number. For example, if you are upgrading to version 4.0, the dependency version in the `pom.xml` file should be `4.0.0`.

Studio upgrades the connector automatically.

== Verify the Upgrade

After you install the latest version of the connector, follow these steps to verify the upgrade:

. In Studio, verify that there are no errors in the *Problems* or *Console* views.
. Check the project `pom.xml` file and verify that there are no problems.
. Test the connection and verify that the operations work.

== Troubleshooting

If there are problems with caching the parameters and caching the metadata, try restarting Studio.

== Revert the Upgrade

If it is necessary to revert to the previous version of Microsoft Dynamics NAV Connector, change the `mule-microsoft-dynamics-nav-connector` dependency version in the project's `pom.xml` file to the previous version.

You must update the project's `pom.xml` file in Anypoint Studio.

== Send SOAP Requests in XML Format

To support Microsoft Dynamics NAV Connector in CloudHub 2.0, the client must provide SOAP requests in raw XML format instead of using Plain Old Java Objects (POJOs).

Follow these steps to send or receive SOAP requests in raw XML format:

. Make sure you have the prerequisites, such as Mule 4.9.0 or later, and obtain the WSDL file.
. Identify all Mule flows that use Microsoft Dynamics NAV SOAP operations.
. For the request body, update the content type to `application/xml` and provide SOAP requests in raw XML format instead of using POJOs.
+
image::ms-dynamics-nav-page-config.png["Page Operation Configuration"]
+
XML for sending SOAP requests directly:
+
[source,xml,linenums]
----
<item:Read xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/" xmlns:item="urn:microsoft-dynamics-schemas/page/item_card">
      <item:No>1000</item:No>
   </item:Read>
----
+
image::ms-dynamics-nav-page-output.png["Transform message of Page Operation"]
+
XML for using the DataWeave transform method to convert JSON to XML payload:
+
[source,xml,linenums]
----
<ee:transform doc:name="Transform Message" doc:id="52c376d8-70de-44b3-b388-4837f0790795">
       <ee:message>
           <ee:set-payload><![CDATA[%dw 2.0
   output application/xml
   ---
   {
       Read @("xmlns": "urn:microsoft-dynamics-schemas/page/item_card"): {
           No: 1000
       }
   }]]></ee:set-payload>
       </ee:message>
   </ee:transform>
----

. For the response body, you will receive SOAP responses in raw XML format and must handle these responses accordingly.
+
XML of a SOAP response:
+
[source,xml,linenums]
----
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/" xmlns:item="urn:microsoft-dynamics-schemas/page/item_card">
   <soapenv:Header/>
   <soapenv:Body>
      <item:Read_Result>
         <item:Item>
            <item:No>Returned_1000</item:No>
            <item:Description>Returned_Awesome_Product</item:Description>
            <item:UnitPrice>100.00</item:UnitPrice>
         </item:Item>
      </item:Read_Result>
   </soapenv:Body>
</soapenv:Envelope>
----
+
XML for using the DataWeave method to transform XML payload:
+
[source,xml,linenums]
----
<ee:transform doc:name="Transform Response">
    <ee:message>
        <ee:set-payload><![CDATA[%dw 2.0
output application/java
ns soapenv http://schemas.xmlsoap.org/soap/envelope/
ns item urn:microsoft-dynamics-schemas/page/item_card
---
payload.soapenv#Envelope.soapenv#Body.item#Read_Result.item#Item
]]></ee:set-payload>
    </ee:message>
</ee:transform>
----
