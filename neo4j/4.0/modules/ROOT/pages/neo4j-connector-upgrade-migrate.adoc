= Upgrading and Migrating Neo4j Connector to Version 4.0.0

Upgrade Anypoint Connector for Neo4j (Neo4j Connector) to version 4.0.0.

== Supported Upgrade Paths

[%header,cols="50a,50a"]
|===
|From Version | To Version
|3.0.x |4.0.0
|===

== Changes in This Release

This release contains significant modernization and breaking changes:

=== **Breaking Changes**

* **Neo4j Driver Upgrade**: Upgraded from Neo4j Java Driver 1.7.6 to 5.28.8
* **Minimum Neo4j Server**: Now requires Neo4j 4.4+ (previously supported Neo4j 3.x)
* **Java Runtime**: Minimum JDK 17 (upgraded from JDK 8)
* **Mule Runtime**: Minimum Mule Runtime 4.9.0 (upgraded from 4.1.x)
* **Configuration Simplification**: Removed REST URL parameter from connector configuration

=== **Feature Enhancements**

* **Improved Metadata Resolution**: Complete overhaul of input and output metadata resolution for better Anypoint Studio experience
* **Enhanced Neo4j 5.x Support**: Full compatibility with Neo4j 5.x and 2025.x server features
* **Modern Driver Features**: Access to reactive APIs, multi-database support, and enhanced security
* **Configuration Deprecation Fixes**: Updated Docker configuration settings to use current Neo4j standards

=== **Configuration Changes**

* **Removed Parameters**: The `REST URL` configuration parameter has been eliminated
* **Simplified Setup**: Only BOLT URL configuration is now required
* **Metadata Source**: All metadata operations now use native Cypher queries through BOLT connection instead of REST API calls

== Requirements

Ensure that you meet these requirements before you perform the upgrade:

=== **Neo4j Server Requirements**
* **Minimum Neo4j Server**: 4.4 LTS or higher
* **Recommended**: Neo4j 5.26 LTS or Neo4j 2025.06+
* **Unsupported**: Neo4j 3.x servers (breaking change)

=== **Java Runtime Requirements**
* **Minimum JDK**: 17
* **Supported JDK versions**: 17
* **Unsupported**: JDK 8, 11 (breaking change)

=== **Mule Runtime Requirements**
* **Minimum Mule Runtime**: 4.9.0
* **Reason**: Required for JDK 17 support and unified connectors parent compatibility
* **Unsupported**: Mule Runtime 4.1.x - 4.8.x (breaking change)

=== **Development Environment**
* **Anypoint Studio**: Latest version supporting Mule Runtime 4.9.0+
* **Maven**: Version supporting JDK 17+

== Limitations

Before you perform the upgrade, be aware of these known limitations:

=== **Breaking Changes Limitations**
* **No automatic migration**: Applications must be manually updated to support new requirements
* **No rollback mechanism**: Once upgraded, rolling back requires restoring from backup
* **Server dependency**: Neo4j 3.x servers cannot be used with connector version 4.0.0
* **Runtime dependency**: Applications must run on Mule Runtime 4.9.0+ and JDK 17+

=== **Configuration Migration**
* **REST URL removal**: Existing configurations using REST URL parameter must be updated
* **Connection testing**: All existing connections should be re-tested after upgrade
* **Metadata regeneration**: Studio metadata may need to be refreshed for operations

=== **Development Impact**
* **Build system**: Maven builds require JDK 17+ toolchain
* **Testing environment**: Test servers must be upgraded to Neo4j 4.4+ before connector testing

== Upgrade Prerequisites

Before you perform the upgrade, you must complete the following:

=== **Environment Preparation**
* **Create a backup** of your Mule applications, data, and configurations
* **Upgrade Neo4j Server** to version 4.4 LTS or higher (if currently using Neo4j 3.x)
* **Upgrade Mule Runtime** to version 4.9.0 or higher
* **Upgrade JDK** to version 17 or higher on all environments (development, test, production)

=== **Application Assessment**
* **Review existing configurations** to identify REST URL usage
* **Document current BOLT URL settings** for post-upgrade validation
* **Test connectivity** to ensure Neo4j servers are accessible via BOLT protocol
* **Identify custom error handling** that may reference connector-specific error types

== Upgrade the Connector in Anypoint Code Builder

Follow these steps to perform the upgrade:

. In *Explorer*, right-click the configuration XML file in your integration project, and select *Project Properties*.
. In *Project Properties*, select *Connectors*.
. Select the latest version for the connector, and click *Apply*.

== Upgrade the Connector in Studio

Follow these steps to perform the upgrade:

. In Anypoint Studio, open your existing Mule project.
. In *Mule Palette*, click *Search in Exchange*.
. In *Add Dependencies to Project*, enter `neo4j` in the search field.
. In *Available modules*, select *Neo4j Connector* and click *Add*.
. Click *Finish*.
. Verify that the Neo4j Connector `<dependency>` version is `4.0.0` in the `pom.xml` file in the Mule project:
+
[source,xml,linenums]
----
<dependency>
  <groupId>com.mulesoft.connectors</groupId>
  <artifactId>mule-neo4j-connector</artifactId>
  <version>4.0.0</version>
  <classifier>mule-plugin</classifier>
</dependency>
----

Studio upgrades the connector automatically, but configuration changes are required.

== Post Upgrade Steps

After you install the latest version of the connector, follow these steps to complete the upgrade:

=== **Configuration Migration**

==== **Remove REST URL Parameter**

The REST URL parameter has been removed from the connector configuration. Update your configurations:

**Before (Version 3.x):**
[source,xml,linenums]
----
<neo4j:config name="Neo4j_Config" doc:name="Neo4j Config">
    <neo4j:connection username="${config.username}"
                     password="${config.password}"
                     boltUrl="${config.boltUrl}"
                     restUrl="${config.restUrl}" />
</neo4j:config>
----

**After (Version 4.0.0):**
[source,xml,linenums]
----
<neo4j:config name="Neo4j_Config" doc:name="Neo4j Config">
    <neo4j:connection username="${config.username}"
                     password="${config.password}"
                     boltUrl="${config.boltUrl}" />
</neo4j:config>
----

==== **Update Connection Properties**

Remove the REST URL property from your configuration files:

**Before:**
[source,text,linenums]
----
config.username=<USERNAME>
config.password=<PASSWORD>
config.boltUrl=<BOLT_URL_ENDPOINT>
config.restUrl=<REST_URL_ENDPOINT>  <!-- Remove this line -->
----

**After:**
[source,text,linenums]
----
config.username=<USERNAME>
config.password=<PASSWORD>
config.boltUrl=<BOLT_URL_ENDPOINT>
----

=== **Runtime Environment Updates**

. **Update Mule Runtime**: Ensure all environments are running Mule Runtime 4.9.0+
. **Update JDK**: Verify all environments are using JDK 17+
. **Update Neo4j Servers**: Ensure Neo4j servers are version 4.4+ or 5.x

=== **Metadata Refresh**

. **Regenerate metadata** in Anypoint Studio for improved design-time experience
. **Test operations** to ensure metadata is properly resolved
. **Validate DataWeave expressions** benefit from enhanced type information

=== Verify the Upgrade

After you install the latest version of the connector, verify the upgrade:

. **Validate Configuration**: Ensure no REST URL references remain in configurations
. **Check Dependencies**: Verify `pom.xml` shows version 4.0.0 of the Neo4j connector
. **Test Connection**: Use the "Test Connection" feature to validate BOLT connectivity
. **Verify Metadata**: Check that operations show comprehensive field suggestions in Studio
. **Run Tests**: Execute existing unit tests to ensure functionality is preserved
. **Check Logs**: Verify no deprecation warnings appear during application startup

== Troubleshooting

=== **Common Upgrade Issues**

==== **Connection Failures After Upgrade**

**Issue**: Cannot connect to Neo4j server after upgrade
**Solution**: 
* Verify Neo4j server is version 4.4+ (Neo4j 3.x is no longer supported)
* Ensure BOLT protocol is enabled on Neo4j server
* Remove any REST URL references from configuration

**Example Error**: `Neo4j.ClientError.Security.Unauthorized`
**Resolution**: Verify credentials and server accessibility via BOLT port (default 7687)

==== **Metadata Not Displaying in Studio**

**Issue**: Operations show empty metadata or missing field suggestions
**Solution**:
* Ensure sample data exists in your Neo4j database for the labels you're using
* Regenerate metadata by refreshing the connector in Studio
* Verify BOLT connection is working properly

==== **Runtime Compatibility Issues**

**Issue**: Application fails to start with JDK or Mule Runtime errors
**Solution**:
* Upgrade to JDK 17+ (JDK 8/11 no longer supported)
* Upgrade to Mule Runtime 4.9.0+ (earlier versions incompatible)
* Update Maven build configuration for JDK 17 compatibility

=== Reverting the Upgrade

If you need to revert to version 3.x:

. **Restore from backup** of your Mule application and configurations
. **Downgrade dependencies** in `pom.xml` to version 3.x
. **Restore REST URL parameter** in connector configurations
. **Verify compatibility** with your current Mule Runtime and JDK versions

**Note**: Reverting requires restoring to environments compatible with version 3.x requirements.
