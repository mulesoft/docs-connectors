[[debug]]
== Debug the App

Debug your Mule application using the embedded debugger in Anypoint Code Builder.

Before debugging your app, add the `Dmule.http.service.implementation=NETTY` property to your debug configuration.

See xref:anypoint-code-builder::int-debug-mule-apps.adoc[].

[[deploy]]
== Deploy the App

Before you deploy the app:

. Add the `Dmule.http.service.implementation=NETTY` property to your app in Runtime Manager for CloudHub and Runtime Fabric deployments. 
+
For hybrid deployments, add the property to whatever you use to start Mule apps.
