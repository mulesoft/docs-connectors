= Upgrading and Migrating Oracle EBS 12.1 Connector to 6.x

Upgrade Anypoint Connector for Oracle E-Business Suite (Oracle EBS 12.1 Connector) from version 5.x to version 6.x.

== Supported Upgrade Paths

[%header,cols="50a,50a"]
|===
|From Version | To Version
|5.x |6.x
|===

== Changes in This Release

=== 6.0

* The PL/SQL connection now includes *Read Timeout Unit*, *Connection Idle Timeout*, *Connection Timeout Unit*, and HTTP proxy fields. For more information, see xref:oracle-ebs-connector-reference.adoc#plsql-config_plsql[PLSQL Connection Type].
* Payload fields for web service operations, the *Invoke PL SQL* operation, and the *XML Gateway* operation now use the Any type, instead of Binary. The *Invoke PL SQL* operation, the *Business Events* source, and the *XML Gateway Outbound* source also return Any. For more information, see xref:oracle-ebs-connector-reference.adoc#invokePlSql[Invoke PL SQL], xref:oracle-ebs-connector-reference.adoc#BusinessEventsSource[Business Events Source], and xref:oracle-ebs-connector-reference.adoc#XmlGatewayOutboundSource[XML Gateway Outbound Source].
* The redelivery policy now identifies messages with *Message Identifier*. *Use Secure Hash* and *Id Expression* are fields of that type. For more information, see xref:oracle-ebs-connector-reference.adoc#RedeliveryPolicy[Redelivery Policy] and xref:oracle-ebs-connector-reference.adoc#RedeliveryPolicyMessageIdentifier[Redelivery Policy Message Identifier].
* The repeatable file-store stream field *Max In Memory Size* is now *In Memory Size*. For more information, see xref:oracle-ebs-connector-reference.adoc#repeatable-file-store-stream[Repeatable File Store Stream].

== Requirements

Ensure your system meets the following compatibility requirements before you perform the upgrade:

[%header%autowidth.spread]
|===
|Application/Service|Version
|Mule runtime |4.1.1 and later
|Oracle EBS |12.1.x
|OpenJDK |8, 11, and 17
|===

== Upgrade Prerequisites

Before you perform the upgrade, you must:

. Create a backup of your files, data, and configuration in case you need to restore to the previous version.
. Ensure that your environment meets the version 6.x requirements.
. Review applications that set *Max In Memory Size* on a repeatable file-store stream, or that set *Use Secure Hash* and *Id Expression* directly on the redelivery policy.
. Install Oracle EBS 12.1 Connector 6.x to replace the connector operations that were previously included in version 5.x.

== Upgrade Steps

Follow these steps to perform the upgrade from Oracle EBS 12.1 Connector 5.x to Oracle EBS 12.1 Connector 6.x:

. In Anypoint Studio, create a Mule project.
. In the Mule Palette view, click *Search in Exchange*.
. In the *Add Dependencies to Project* window, enter `Oracle EBS` in the search field.
. In the *Available modules* section, select *Oracle EBS 12.1 Connector* and click *Add*.
. Click *Finish*.
. Verify that the `mule-oracle-ebs-connector` dependency version is `6.x.x` in the `pom.xml` file, where `x.x` is the minor release and patch version number. For example, if you are upgrading to version 6.0, the dependency version in the `pom.xml` file should be `6.0.0`.

Studio upgrades the connector automatically.

== Verify the Upgrade

After you install the latest version of the connector, follow these steps to verify the upgrade:

. In Studio, verify that there are no errors in the *Problems* or *Console* views.
. Check the project `pom.xml` file and verify that there are no problems.
. Test the connection and verify that the operations work.

== Troubleshooting

If there are problems with caching the parameters and caching the metadata, try restarting Studio.

== Revert the Upgrade

If it is necessary to revert to the previous version of Oracle EBS 12.1 Connector, change the `mule-oracle-ebs-connector` dependency version in the project's `pom.xml` file to `5.3.5`.

Rollback is a connector downgrade. There is no data migration.

You must update the project's `pom.xml` file in Anypoint Studio.
