= Upgrading and Migrating Oracle EBS 12.1 Connector to 6.x

Upgrade Anypoint Connector for Oracle E-Business Suite (Oracle EBS 12.1 Connector) from version 5.x to version 6.x.

== Supported Upgrade Paths

[%header,cols="50a,50a"]
|===
|From Version | To Version
|5.x |6.x
|===

== Changes in This Release

=== 6.0

* This connector is now compatible with Java 17 only.
* Apache CXF is upgraded to 4.2.4 and PL/SQL requests now use Mule SOAP Engine 3.0.3 instead of the deprecated Mule SOAP service. These upgrades address reported security vulnerabilities.
* PL/SQL and Web Services connections now include separate *Read Timeout*, *Connection Timeout*, and *Connection Idle Timeout* fields with corresponding *Read Timeout Unit*, *Connection Timeout Unit*, and *Connection Idle Timeout Unit* fields. Each timeout defaults to `30` with a unit of `SECONDS`. The PL/SQL *Read Timeout* previously defaulted to `30000` milliseconds, so its effective duration remains 30 seconds. HTTP proxy fields remain available for PL/SQL. For more information, see xref:oracle-ebs-connector-reference.adoc#plsql-config_plsql[PLSQL Connection Type] and xref:oracle-ebs-connector-reference.adoc#web-services-config_web-services[Web Services Connection Type].
* PL/SQL and Web Services connections now support *TLS Context*. For Web Services, this replaces *TrustStore file name*, *TrustStore password*, and *Disable Common Name checking*. For more information, see xref:oracle-ebs-connector-reference.adoc#Tls[TLS].
* The source XML elements are now `business-events-listener` and `xml-gateway-outbound-listener`, instead of `business-events-source` and `xml-gateway-outbound-source`. For more information, see xref:oracle-ebs-connector-reference.adoc#BusinessEventsListener[*Business Events Listener*] and xref:oracle-ebs-connector-reference.adoc#XmlGatewayOutboundListener[*XML Gateway Outbound Listener*].
* Payload fields for web service operations, the *Invoke PL SQL* operation, and the *XML Gateway* operation now use the Any type, instead of Binary. The *Invoke PL SQL* operation and both listeners also return Any. For more information, see xref:oracle-ebs-connector-reference.adoc#invokePlSql[*Invoke PL SQL*], xref:oracle-ebs-connector-reference.adoc#BusinessEventsListener[*Business Events Listener*], and xref:oracle-ebs-connector-reference.adoc#XmlGatewayOutboundListener[*XML Gateway Outbound Listener*].
* The redelivery policy now identifies messages with *Message Identifier*. *Use Secure Hash* and *Id Expression* are fields of that type. For more information, see xref:oracle-ebs-connector-reference.adoc#RedeliveryPolicy[Redelivery Policy] and xref:oracle-ebs-connector-reference.adoc#RedeliveryPolicyMessageIdentifier[Redelivery Policy Message Identifier].
* The repeatable file-store stream field *Max In Memory Size* is now *In Memory Size*. For more information, see xref:oracle-ebs-connector-reference.adoc#repeatable-file-store-stream[Repeatable File Store Stream].
* Error handling now distinguishes Oracle EBS service faults with `ORACLE-EBS:SERVICE_ERROR` and payload-conversion failures with `ORACLE-EBS:TRANSFORMATION`. Unclassified errors use `MULE:UNKNOWN`, instead of `ORACLE-EBS:UNKNOWN`.
* `ORACLE-EBS:ILLEGAL_ARGUMENT` now inherits from `MULE:VALIDATION`, instead of connectivity. `ORACLE-EBS:UNSUPPORTED_OPERATION` now inherits from `MULE:ANY`, instead of connectivity. Review error mappings and retry logic that catch connectivity errors.
* Custom PL/SQL WSDLs now undergo secure validation. DOCTYPE declarations, XInclude, and imports, includes, or redefines with nonempty external locations are rejected, whether the locations are relative or absolute. Rejected WSDLs cause `ORACLE-EBS:INVALID_WSDL`.
* PL/SQL invocation endpoints now include a trailing slash (`/plsql/<package>/`) to match Oracle EBS Integrated SOA Gateway requirements.
* PL/SQL connection retries now retain successfully created SOAP clients after a partial connection failure and recreate only missing clients while the connection configuration is unchanged.
* The *Business Events Listener* and *XML Gateway Outbound Listener* now close their consumers before their JMS sessions and don't trigger reconnection when stopped. For more information, see xref:oracle-ebs-connector-reference.adoc#BusinessEventsListener[*Business Events Listener*] and xref:oracle-ebs-connector-reference.adoc#XmlGatewayOutboundListener[*XML Gateway Outbound Listener*].
* Connector Java packages now use `com.mulesoft.connectors.oracleebs`, instead of `org.mule.modules.oracle`. This change also applies to generated model classes. Update Java imports and DataWeave references to fully qualified model class names. Review custom JAXB integrations for compatibility with the Jakarta JAXB API.
* These libraries are upgraded to address reported security vulnerabilities:

** The Apache CXF libraries are upgraded to version 4.2.4.
** The `guava` library is upgraded to version 33.8.0-jre.
** The `gson` library is upgraded to version 2.15.0.
** The `commons-lang3` library is upgraded to version 3.21.0.
** The `xmlsec` library is upgraded to version 4.0.4.
** The `jakarta.xml.bind-api` library is upgraded to version 4.0.5.
** The `jaxb-runtime` library is upgraded to version 4.0.9.
** The `jakarta.xml.ws-api` library is upgraded to version 4.0.3.
** The `jakarta.xml.soap-api` library is upgraded to version 3.0.2.
** The `saaj-impl` library is upgraded to version 3.0.6.

== Upgrade Prerequisites

Before you perform the upgrade, you must:

. Create a backup of your files, data, and configuration in case you need to restore to the previous version.
. Ensure that your environment meets the version 6.x requirements.
. Review applications that set *Max In Memory Size* on a repeatable file-store stream, or that set *Use Secure Hash* and *Id Expression* directly on the redelivery policy.
. Review explicit timeout values and units. If you retain a value of `30000`, set its unit to `MILLISECONDS` to preserve a 30-second timeout.
. To preserve the previous PL/SQL connection and idle timeout settings, set both *Connection Timeout* and *Connection Idle Timeout* to the previous *Connection Idle Timeout* value. Set both *Connection Timeout Unit* and *Connection Idle Timeout Unit* to the previous *Connection Timeout Unit* value.
. Replace the Web Services *TrustStore file name*, *TrustStore password*, and *Disable Common Name checking* fields with *TLS Context* and verify your certificate validation settings.
. Rename source elements to `business-events-listener` and `xml-gateway-outbound-listener` in the application XML.
. Update error handlers that reference `ORACLE-EBS:UNKNOWN` and review the new service, transformation, and WSDL errors.
. Review handlers and retry logic that catch connectivity errors. Service faults, illegal arguments, and unsupported operations no longer belong to the connectivity error hierarchy.
. Ensure custom PL/SQL WSDLs meet the secure validation requirements.
. Ensure custom PL/SQL WSDL endpoints return self-contained WSDLs directly, without HTTP redirects. Include required WSDL and XML Schema definitions within the document.
. When using custom PL/SQL packages, ensure the runtime user can create, write, and restrict access to the `${user.home}/.mulesoft/oracle-ebs-connector/wsdl-cache` directory. The connector deletes cached WSDL files during disconnect or stop.
. Verify that externally supplied Oracle JDBC and AQ libraries support Java 17 and work together in your deployment. The connector declares Oracle JDBC `ojdbc8` version `19.33.0.0` and AQ API version `19.3.0.0` as provided dependencies. These declarations don't replace the libraries supplied by your application.
. Install Oracle EBS 12.1 Connector 6.x to replace the connector operations that were previously included in version 5.x.

== Upgrade Steps

Follow these steps to perform the upgrade from Oracle EBS 12.1 Connector 5.x to Oracle EBS 12.1 Connector 6.x:

. In Anypoint Studio, create a Mule project.
. In the Mule Palette view, click *Search in Exchange*.
. In the *Add Dependencies to Project* window, enter `Oracle EBS` in the search field.
. In the *Available modules* section, select *Oracle EBS 12.1 Connector* and click *Add*.
. Click *Finish*.
. Verify that the `mule-oracle-ebs-connector` dependency version is `6.x.x` in the `pom.xml` file, where `x.x` is the minor release and patch version number. For example, if you are upgrading to version 6.0, the dependency version in the `pom.xml` file should be `6.0.0`.

Studio updates the connector dependency. You must also make the configuration changes described in <<upgrade-prerequisites,Upgrade Prerequisites>>.

== Verify the Upgrade

After you install the latest version of the connector, follow these steps to verify the upgrade:

. In Studio, verify that there are no errors in the *Problems* or *Console* views.
. Check the project `pom.xml` file and verify that there are no problems.
. Test the connection and verify that the operations work.
. Verify DataSense and invocation for both bundled and custom PL/SQL packages, including connections that use TLS or an HTTP proxy.
. Start and stop both JMS listeners and verify subscriptions and message delivery in your deployment environment.

For durable *Business Events Listener* subscriptions, an omitted or empty *Subscription Name* continues to default to `muleBusinessEvents`. This behavior is unchanged from 5.x.

== Troubleshooting

If there are problems with caching the parameters and caching the metadata, try restarting Studio.

For an `ORACLE-EBS:INVALID_WSDL` error, use a self-contained custom PL/SQL WSDL without DOCTYPE declarations or XInclude. Inline required WSDL and XML Schema definitions rather than only removing their external location attributes.

For `ORACLE-EBS:CONNECTIVITY` during WSDL retrieval, check the endpoint, credentials, proxy, TLS, and timeout settings. Ensure the endpoint returns the WSDL directly without an HTTP redirect. Also check that the runtime user's home directory is writable and that the connector can create and restrict access to its WSDL cache directory.

== Revert the Upgrade

If it is necessary to revert to the previous version of Oracle EBS 12.1 Connector, change the `mule-oracle-ebs-connector` dependency version in the project's `pom.xml` file to `5.3.5`.

Rollback is a connector downgrade. There is no data migration.

Restore the backed-up 5.x configuration, including source names, TLS settings, timeout values, and error handlers. Revert custom Java package references if you changed them.

You must update the project's `pom.xml` file in Anypoint Studio.
