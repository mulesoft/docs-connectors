= HashiCorp Vault Properties Provider 1.0

HashiCorp Vault Properties Provider is a configuration that enables Mule applications to retrieve secrets and configuration properties from HashiCorp Vault before the Mule app runs.

For information about compatibility and fixed issues, refer to the HashiCorp Vault Properties Provider Release Notes.

== Before You Begin

To use this properties provider, you must be familiar with:

* HashiCorp Vault and its key-value version 2 secrets engine
* Anypoint Connectors
* Mule runtime engine (Mule)
* Elements and global elements in a Mule flow
* How to create a Mule app using Anypoint Studio

Before creating an app, you must have:

* Mule Enterprise Edition
* The URL of your Vault server and credentials to access it (a token, AppRole credentials, or LDAP credentials)
* Anypoint Platform
* Anypoint Studio or Anypoint Code Builder

== Common Use Cases for the Properties Provider

With HashiCorp Vault Properties Provider, secrets are retrieved in the pre-runtime phase, which means secrets are populated before the Mule app is deployed.

== Configure the Properties Provider

Select exactly one authentication type: Token, AppRole, or LDAP. This example uses token authentication:

[source,xml,linenums]
----
<hashicorp-vault-properties-provider:config name="HashiCorp_Vault_Properties_Provider_Config">
    <hashicorp-vault-properties-provider:token-authentication vaultToken="${vault.token}"/>
</hashicorp-vault-properties-provider:config>
----

For all configuration fields, refer to xref:hashicorp-vault-properties-provider-reference.adoc[HashiCorp Vault Properties Provider Reference].

== Reference Secrets

To retrieve a secret, use the `${hashicorp::path#field}` structure, where `path` is the path of the secret in the Vault secrets mount and `field` is the name of the field in that secret. For example, `${hashicorp::myapp/database#password}`.

== Known Limitations

* The properties provider supports only the Vault key-value version 2 secrets engine.
* Select exactly one authentication type for each configuration.
