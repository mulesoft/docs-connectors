[[Config]]
=== Config


Default configuration


==== Parameters

[%header%autowidth.spread]
|===
| Name | Type | Description | Default Value | Required
|Name | String | The name for this configuration. Connectors reference the configuration with this name. | | x
| Connection a| <<Config_Hmac, HMAC Signed Webhook Connection>>
 | The connection types to provide to this configuration. | | x
| Response Timeout a| Number |  Maximum time to wait for a Spiff response; operations can override it |  60 | 
| Response Timeout Unit a| Enumeration, one of:

** NANOSECONDS
** MICROSECONDS
** MILLISECONDS
** SECONDS
** MINUTES
** HOURS
** DAYS |  Time unit for the response timeout |  SECONDS | 
| Name a| String |  The identifier of this element used to reference it in other components |  | x
| Expiration Policy a| <<ExpirationPolicy>> |  Configures the minimum amount of time that a dynamic configuration instance can remain idle before Mule considers it eligible for expiration. This does not mean that the platform expires the instance at the exact moment that it becomes eligible. Mule purges the instances as appropriate. |  | 
|===

====== Parameters

[%header%autowidth.spread]
|===

| Company UUID a| String |  Spiff company UUID (Spiff Admin > Settings > Company Settings), sent as company_uuid on every signed mutation |  | x
| Connection Timeout a| Number |  Time to wait for a TCP connection to be established; also used as the response timeout of Test Connection |  30 | 
| Connection Timeout Unit a| Enumeration, one of:

** NANOSECONDS
** MICROSECONDS
** MILLISECONDS
** SECONDS
** MINUTES
** HOURS
** DAYS |  Time unit for the connection timeout |  SECONDS | 
| Use Persistent Connections a| Boolean |  Whether to reuse TCP connections across requests |  true | 
| Max Connections a| Number |  Maximum simultaneous outbound connections, unlimited by default |  -1 | 
| Connection Idle Timeout a| Number |  Time a connection can stay idle before closing, applicable only when persistent connections are enabled |  30 | 
| Connection Idle Timeout Unit a| Enumeration, one of:

** NANOSECONDS
** MICROSECONDS
** MILLISECONDS
** SECONDS
** MINUTES
** HOURS
** DAYS |  Time unit for the connection idle timeout |  SECONDS | 
| Stream Response a| Boolean |  When enabled, allows processing to begin after headers are parsed. The response must be read eventually to avoid memory issues. |  false | 
| Response Buffer Size a| Number |  Space in bytes for the buffer where the HTTP response will be stored |  -1 | 
| Proxy Configuration a| One of:

* <<Default>>
* <<Ntlm>> |  Outbound HTTP proxy used to reach Spiff |  | 
| TLS Configuration a| <<Tls>> |  When using HTTPS, the TLS configuration to use for securing the connection |  | 
| Default Headers a| Array of <<DefaultHeader>> |  Custom headers to include in every request |  | 
| Default Query Parameters a| Array of <<DefaultQueryParam>> |  Custom query parameters to include in every request |  | 
| Reconnection a| <<Reconnection>> |  When the application is deployed, a connectivity test is performed on all connectors. If set to true, deployment fails if the test doesn't pass after exhausting the associated reconnection strategy. |  |
