= Spiff Connector 1.0 XML and Maven Support - Mule 4

Although you can manually code a Mule app in XML, it is more efficient to use Anypoint Studio or Anypoint Code Builder.

If you manually code a Mule runtime engine (Mule) app in XML, either from Studio or from a text editor, you can get access
to the connector from your app by adding reference statements to both your XML Mule flow and the Apache Maven POM file.

When you add the connector in Studio, Studio automatically populates the XML code with the connector's namespace and
schema location. Studio also adds a dependency to the project's `pom.xml` file.

== Add a Namespace for the Connector

Paste the following code inside the `<mule>` tag of the header of your configuration XML:

[source,text,linenums]
----
http://www.mulesoft.org/schema/mule/spiff
http://www.mulesoft.org/schema/mule/spiff/current/mule-spiff.xsd
----

This example shows how the namespace statements are placed in the `<mule>` XML block:

[source,xml,linenums]
----
<mule xmlns="http://www.mulesoft.org/schema/mule/core"
      xmlns:spiff="http://www.mulesoft.org/schema/mule/spiff"
      xmlns:http="http://www.mulesoft.org/schema/mule/http"
      xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
      xsi:schemaLocation="http://www.mulesoft.org/schema/mule/core http://www.mulesoft.org/schema/mule/core/current/mule.xsd
        http://www.mulesoft.org/schema/mule/spiff http://www.mulesoft.org/schema/mule/spiff/current/mule-spiff.xsd
        http://www.mulesoft.org/schema/mule/http http://www.mulesoft.org/schema/mule/http/current/mule-http.xsd">

    <!-- Put your flows and configuration elements here -->

</mule>
----

== Add a POM File Dependency

The Apache Maven `pom.xml` file generated by Anypoint Studio contains dependencies for a Mule app. If you code a Mule app
manually, include this XML snippet in your `pom.xml` file to enable access to this connector:

[source,xml,linenums]
----
<dependency>
    <groupId>com.mulesoft.connectors</groupId>
    <artifactId>mule4-spiff-connector</artifactId>
    <version>1.0.0</version>
    <classifier>mule-plugin</classifier>
</dependency>
----

Use the version that corresponds to the connector you are using. The connector requires Mule 4.9.0 or later and Java 17.

To obtain the most up-to-date `pom.xml` file information:

. Go to https://www.mulesoft.com/exchange/[Anypoint Exchange].
. In Exchange, click *Login* and supply your Anypoint Platform username and password.
. In Exchange, search for `spiff`.
. Select the connector.
. Click *Dependency Snippets* near the upper right of the screen.

== Configure the Connection in XML

[source,xml,linenums]
----
<spiff:config name="Spiff_Config" responseTimeout="60" responseTimeoutUnit="SECONDS">
    <spiff:hmac-connection subdomain="${spiff.subdomain}"
                           connectorId="${spiff.connectorId}"
                           webhookSecret="${secure::spiff.webhookSecret}"
                           companyUuid="${spiff.companyUuid}"
                           connectionTimeout="30"/>
</spiff:config>
----

The `${secure::...}` reference requires the Secure Configuration Properties module in the app. See
xref:mule-runtime::secure-configuration-properties.adoc[Secure Configuration Properties].
