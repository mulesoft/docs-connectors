== Configure the Connection in XML

[source,xml,linenums]
----
<spiff:config name="Spiff_Config" responseTimeout="60" responseTimeoutUnit="SECONDS">
    <spiff:hmac-connection subdomain="${spiff.subdomain}"
                           connectorId="${spiff.connectorId}"
                           webhookSecret="${secure::spiff.webhookSecret}"
                           companyUuid="${spiff.companyUuid}"
                           connectionTimeout="30"/>
</spiff:config>
----

The `${secure::...}` reference requires the Secure Configuration Properties module in the app. See
xref:mule-runtime::secure-configuration-properties.adoc[Secure Configuration Properties].
