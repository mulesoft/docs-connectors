[[adhoc-file-query]]
== Configure the Adhoc File Query Operation

The *Embedding Adhoc File Query* operation takes a document and ingests it into the vector database along with its query. 

The output of this operation is a set of scores with the complete content of the document that's the most likely the answer to the query. The vector database is used to identify the numeric representation of the content before creating the likely score.
