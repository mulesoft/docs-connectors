= FTPS Connector 3.0
:page-aliases: connectors::ftp/ftps-connector.adoc

Support Category: https://www.salesforce.com/en-us/wp-content/uploads/sites/4/documents/legal/Agreements/versioning-back-support-policy.pdf[Premium]

Anypoint Connector for FTPS (FTPS Connector) connects to FTP servers the same way as the xref:ftp-connector::index.adoc[FTP Connector] but adds support for xref:mule-runtime::tls-configuration.adoc[Transport Layer Security (TLS)].

FTPS Connector 3.0 requires Mule 4.9.0 or later and Java 17. It is a standalone connector and no longer includes FTP Connector. For the behavior that changes when you upgrade, see xref:ftps-connector-upgrade-guide.adoc[].

== Before You Begin

To use this connector, you must be familiar with:

* Anypoint Connectors
* Mule runtime engine (Mule)
* Elements and global elements in a Mule flow
* Creating a Mule app using Anypoint Studio or Anypoint Code Builder

Before creating an app, you must have access to Anypoint Platform and Anypoint Studio.
