= Configuring a Proxy for FTPS Connector

Anypoint Connector for FTPS (FTPS Connector) enables you to configure an HTTP or HTTPS tunnel proxy. *Proxy host* is required. *Proxy port* defaults to `3128`. *Proxy username* and *Proxy password* are optional and are required only if the proxy server is authenticated. If the TLS handshake with the HTTPS tunnel proxy fails, for example because the proxy presents an untrusted certificate, the connection fails with `FTPS:TLS_HANDSHAKE_FAILED`.

The following example shows how to configure the *Proxy Configuration* field:

. In Studio, select your FTPS Connector operation from the canvas.
. In the configuration screen for the operation, click the plus sign (*+*) next to *Connector configuration* to access the global element configuration fields.
. On the *General* tab, specify the connection information for the connector.
. On the *Proxy* tab, set *Proxy Configuration* to *Https tunnel proxy*.
. Set *TLS Configuration* to *Edit inline*.
. For *Trust Store Configuration*, select *Insecure*.
. Set the following fields:

* *Proxy host*: `localhost`
* *Proxy port*: `3129`
* *Proxy username*: `userprox`
* *Proxy password*: `passprox`

[start=8]
. Click *OK*.

image::ftps-proxy-configuration.png[FTPS Connector Global Element Configuration window with Proxy field set to HTTPS tunnel proxy]

In the *Configuration XML* tab, the configuration `ftps:https-tunnel-proxy` looks like this:
[source,xml,linenums]
----
<ftps:config name="FTPS_Config">
		<ftps:connection host="ftps" username="user123" password="pass123" >
			<ftps:proxy >
				<ftps:https-tunnel-proxy host="localhost" port="3129" username="userprox" password="passprox" >
					<tls:context >
						<tls:trust-store insecure="true" />
					</tls:context>
				</ftps:https-tunnel-proxy>
			</ftps:proxy>
		</ftps:connection>
	</ftps:config>
----

The *Insecure* trust store is shown only as an example. In production, configure a trust store that contains the proxy certificate.
