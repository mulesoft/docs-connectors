== Changes in This Release

This release contains the following changes:

* FTPS connector now supports `Java 17`.
* It is now `FIPS 140-2 compliant`.
* FTPS connector no longer uses Reflection to reuse SSL Session from the command channel to data channels. It now uses `Bouncy Castle` libraries provided externally by the client to achieve SSL Session resumption between client and host.
* User may now also provide extra properties as per their requirement:
** jdk.tls.client.protocols
** org.bouncycastle.jsse.client.assumeOriginalHostName
* The `mule-file-commons` module dependency is removed.
* The *List* operation now returns the file path instead of the file content.

== Limitations

Before you perform the upgrade, be aware of these known limitations:

* Session reuse does not work well with TLS 1.3 in CloudHub (same is the case with previous versions of FTPS connector).
* The security providers are hardcoded which will actually mutate the environment i.e. all the mule applications running on the same JVM will share these registered security providers.

Before you perform the upgrade, you must complete the following:

* Create a backup of your files, data, and configurations in case you need to restore to them.

== Upgrade Steps

Follow these steps to perform the upgrade:

. In Anypoint Studio, create a Mule project.
. In *Mule Palette*, click *Search in Exchange*.
. In *Add Dependencies to Project*, enter `FTPS` in the search field.
. In *Available modules*, select *FTPS Connector* and click *Add*.
. Click *Finish*.
. Verify that the FTPS Connector `mule-ftps-connector` version is `2.0.0` in the `pom.xml` file in the Mule project.

Studio upgrades the connector automatically.

=== Verify the Upgrade

After you install the latest version of the connector, verify the upgrade:

. In Studio, verify that there are no errors in the *Problems* or *Console* views.
. Verify that there are no problems in the project `pom.xml` file.
. Test the connection to verify that the operations work.

=== Reverting the Upgrade
If you need to revert to the previous version of SFTP Connector, go to Anypoint Studio and in the project’s `pom.xml` file, change the `mule-ftps-connector` dependency version 2.0.0 to the previous version.
