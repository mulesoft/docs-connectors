= Upgrading and Migrating ServiceNow Connector to 7.x

Upgrade Anypoint Connector for ServiceNow (ServiceNow Connector) from version 6.x to version 7.x.

== Supported Upgrade Paths

[%header,cols="50a,50a"]
|===
|From Version |To Version
|6.x |7.x
|===

== Changes in This Release

=== 7.0

* This connector is now compatible with Java 17 only.
* The SOAP engine is upgraded to version 3.0.3, which is based on Apache CXF 4.x. The `SoapFaultException` class moves from `org.mule.runtime.soap.api.exception` to `org.mule.soap.api.exception`. Update custom code that references the previous package.
* The default *Signature Digest Algorithm* is now `SHA256` instead of `SHA1`. The `SHA1` digest and `RSAwithSHA1` signature options are removed. Signature and canonicalization algorithm values now use uppercase names. Update configurations that use the removed options or previous names. For more information, see xref:servicenow-connector::servicenow-reference.adoc#WssSignConfigurationAdapter[WSS Signing Configuration Adapter].
* You can now configure an HTTP or NTLM proxy and a TLS context for both connection types. For more information, see xref:servicenow-connector::servicenow-reference.adoc#config_basic-connection[Basic Authentication] and xref:servicenow-connector::servicenow-reference.adoc#config_oauth2-auth-code-connection[OAuth 2.0 Authorization Code].
* The new TLS configuration supports enabled protocols, cipher suites, trust stores, key stores, and certificate revocation checks. HTTP and NTLM proxy configurations support authentication and hosts that bypass the proxy. For more information, see xref:servicenow-connector::servicenow-reference.adoc#tls[TLS], xref:servicenow-connector::servicenow-reference.adoc#proxy[Proxy], and xref:servicenow-connector::servicenow-reference.adoc#ntlm-proxy[NTLM Proxy].
* *ServiceNow Version*, *User Tables List*, and *Encoding* are now configured on the global configuration instead of on the connection providers. The global configuration also supports *Read Timeout* and *Read Timeout Unit*. For more information, see xref:servicenow-connector::servicenow-reference.adoc#config[Configuration].
* The *Invoke* operation and the *New / Updated Record* source can now override the global encoding and read timeout settings. For more information, see xref:servicenow-connector::servicenow-reference.adoc#invoke[*Invoke*] and xref:servicenow-connector::servicenow-reference.adoc#new-or-updated-record-listener[*New / Updated Record*].
* *Show Reference Values* on the *Invoke* operation and *Display System References* on the *New / Updated Record* source are now enumerations instead of strings, with the values `TRUE`, `FALSE`, and `ALL`. For more information, see xref:servicenow-connector::servicenow-reference.adoc#invoke[*Invoke*] and xref:servicenow-connector::servicenow-reference.adoc#new-or-updated-record-listener[*New / Updated Record*].
* The read timeout unit XML attribute changes from `readTimeoutUnit` to `readTimeoutTimeUnit` for both HTTP message dispatcher providers. The global configuration also uses the `readTimeoutTimeUnit` XML attribute, displayed as *Read Timeout Unit*. For more information, see xref:servicenow-connector::servicenow-reference.adoc#basic-auth-http-message-dispatcher-provider[Basic Authentication HTTP Message Dispatcher Provider] and xref:servicenow-connector::servicenow-reference.adoc#oauth2-http-message-dispatcher-provider[OAuth2 HTTP Message Dispatcher Provider].
* The *Basic Authentication* connection provider now uses connection caching instead of pooling. The *Pooling Profile* configuration is removed. For more information, see xref:servicenow-connector::servicenow-reference.adoc#config_basic-connection[Basic Authentication].
* Authentication, access-denied, not-found, SOAP fault, and bad response failures now raise declared connector errors. The *Invoke* operation declares `SERVICENOW:SECURITY` and `SERVICENOW:NOT_FOUND`. Request timeouts and dispatch failures raise `SERVICENOW:TIMEOUT` and `SERVICENOW:CANNOT_DISPATCH`. Review error handlers that previously matched generic failures. For more information, see xref:servicenow-connector::servicenow-reference.adoc#invoke[*Invoke*].
* SOAP response headers are now returned as repeatable XML streams. For more information, see xref:servicenow-connector::servicenow-reference.adoc#SoapOutputEnvelope[SOAP Output Envelope].
* Table names used by *Invoke* must contain only ASCII letters, digits, and underscores. Invalid names raise `SERVICENOW:BAD_REQUEST`.
* The SOAP engine and related security dependencies are upgraded to address reported security vulnerabilities. Unused pinned dependencies are removed.
* These libraries are upgraded to address reported security vulnerabilities:

** The Apache CXF libraries are upgraded to version 4.2.4.
** The Apache WSS4J libraries are upgraded to version 4.0.2.
** The `xmlsec` library is upgraded to version 4.0.4.
** The `xmlschema-core` library is upgraded to version 2.3.3.
** The `json` library is upgraded to version 20260814.
** The `commons-lang3` library is upgraded to version 3.21.0.
** The `commons-codec` library is upgraded to version 1.22.1.
** The `woodstox-core` library is upgraded to version 7.2.2.
** The `commons-collections4` library is upgraded to version 4.6.0.
** The `asm` library is upgraded to version 9.11.1.
** The `guava` library is upgraded to version 33.8.0-jre.

== Requirements

Before you upgrade, ensure that your environment uses Mule runtime engine 4.9.0 or later and OpenJDK 17.

== Upgrade Steps

. Update the ServiceNow Connector dependency in your project's `pom.xml` file to version `7.x.x`.
. Update the Mule runtime engine to version 4.9.0 or later and run the application on OpenJDK 17.
. Move the `serviceNowVersion` and `encoding` attributes from the connection provider to the global `servicenow:config` element. Move the `<servicenow:user-tables>` child element out of the connection provider and place it under `<servicenow:config>`, after the connection element.
. Rename `readTimeoutUnit` to `readTimeoutTimeUnit` in existing Basic Authentication and OAuth HTTP message dispatcher configurations.
. If required, configure *Read Timeout* and *Read Timeout Unit* on the global configuration. Configure *Encoding*, *Read Timeout*, and *Read Timeout Time Unit* overrides on the *Invoke* operation or the *New / Updated Record* source when their values differ from the global configuration.
. Replace custom references to `org.mule.runtime.soap.api.exception.SoapFaultException` with `org.mule.soap.api.exception.SoapFaultException`.
. Replace `RSAwithSHA1` with a supported signature algorithm. Replace any explicit `signatureDigestAlgorithm="SHA1"` setting with a supported digest, such as `SHA256`. If no digest is configured, the new default is `SHA256`. Verify that the chosen signing and digest algorithms are compatible with the ServiceNow WS-Security policy.
. Update signature algorithm values to `RSA_WITH_SHA224`, `RSA_WITH_SHA256`, `RSA_WITH_SHA384`, or `RSA_WITH_SHA512`. Update canonicalization algorithm values to `CANONICAL_XML_1_0`, `CANONICAL_XML_1_1`, or `EXCLUSIVE_XML_CANONICALIZATION_1_0`.
. Remove the *Pooling Profile* configuration from Basic Authentication connections.
. Review `on-error` handlers for connector operations. Update handlers that rely on generic failures to handle the declared connector errors that now represent security, not found, SOAP fault, bad response, timeout, and request dispatch failures.
. Review code and transformations that consume SOAP response headers. Header values are now repeatable XML streams rather than strings. HTTP protocol headers in `SoapAttributes` are separate and remain string values.
. Verify that table names passed to *Invoke* contain only ASCII letters, digits, and underscores.
. Test each connector connection and operation after the upgrade.
